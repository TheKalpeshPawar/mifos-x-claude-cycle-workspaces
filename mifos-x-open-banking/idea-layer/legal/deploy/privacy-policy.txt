1. INTRODUCTION
================================================================================

Mifos-X Open Banking ("the App") is a Kotlin Multiplatform (KMP) banking
application connecting Consumer users (retail banking customers) and Field
Officers (agent banking staff) to financial services powered by the Open Bank
Project (OBP) REST API v7.0.0.

We are committed to protecting your personal data and financial privacy. This
Privacy Policy explains what data we collect, how we use it, who we share it
with, and what rights you have.

KEY COMMITMENT: We never sell your data. Financial data is accessed only via
your bank's OBP API and is not transmitted to any other party. Crash diagnostics
on Android contain no financial data.

3. DATA WE COLLECT AND WHY
================================================================================

3.1 FINANCIAL AND ACCOUNT INFORMATION

When you authenticate, we access the following financial data via the OBP API:

  DATA TYPE                     | OBP API ENDPOINT                        | PURPOSE
  ------------------------------|------------------------------------------|---------------------------
  Bank account numbers (masked) | /obp/v7.0.0/my/accounts                 | Account list & balances
  Account balances              | /obp/v7.0.0/accounts/{id}/balances       | Home dashboard
  Transaction history           | /obp/v7.0.0/accounts/{id}/transactions   | Transaction list
  Beneficiary details           | /obp/v7.0.0/.../beneficiaries            | Send money flows
  Payment card info (masked PAN)| /obp/v7.0.0/my/cards                    | Card management
  Standing orders               | /obp/v7.0.0/accounts/{id}/standing-orders| Standing order mgmt
  FX rates                      | /obp/v7.0.0/fx/available-currency-iso-codes | FX rates screen

Financial data is cached locally in an encrypted Room KMP database for offline
display. It is NOT transmitted to any server other than your bank's OBP API.

3.2 AUTHENTICATION CREDENTIALS

  OBP session token: Stored encrypted on-device (Android Keystore / iOS Keychain).
                     Cleared on logout. Max 24-hour session.
  Username:          Transmitted to OBP login endpoint only. NOT stored.
  Password:          NEVER stored. Transmitted over HTTPS to OBP login endpoint
                     only. Never logged.

3.3 CRASH AND PERFORMANCE TELEMETRY (ANDROID ONLY)

  Firebase Crashlytics:
    - Crash stack traces, device model, Android OS version, App version
    - Firebase Installation ID (anonymous)
    - NO financial data, NO account numbers, NO session tokens in crash reports

  Firebase Performance Monitoring:
    - Cold-start time, frame rendering rates, network request latency
    - Network URL slugs only — auth tokens and query parameters are stripped
    - NO financial data in performance traces

  IMPORTANT: Firebase Crashlytics and Firebase Performance Monitoring are
  ANDROID-ONLY features. These SDKs are NOT present in iOS, desktop, or
  web builds of this App.

3.4 FIELD OFFICER CUSTOMER DATA (FIELD OFFICER PERSONA ONLY)

Field Officers performing KYC and customer onboarding collect customer personal
data (name, date of birth, national ID, address, contact details, KYC documents)
which is transmitted to and stored by the OBP API backend. The banking institution
is responsible for the lawful basis and retention of these customer records.

8. SECURITY
================================================================================

- All network communications: HTTPS / TLS 1.2 or higher
- Session tokens: Android Keystore / iOS Secure Enclave encrypted storage
- Local Room KMP database: encrypted at rest
- Passwords: NEVER logged, stored on-device, or transmitted beyond OBP login
- Firebase crash reports: configured to exclude sensitive financial data fields

9. YOUR RIGHTS
================================================================================

GDPR RIGHTS (EEA / UK / Switzerland):

  - Right of Access (Art. 15): Request a copy of personal data held about you
  - Right to Rectification (Art. 16): Request correction of inaccurate data
  - Right to Erasure (Art. 17): Request deletion where no lawful basis remains
  - Right to Restriction (Art. 18): Request restricted processing
  - Right to Data Portability (Art. 20): Request data in machine-readable format
  - Right to Object (Art. 21): Object to processing based on legitimate interests
  - Right to Withdraw Consent: Where processing is consent-based
  - Right to Lodge a Complaint: Contact your national DPA (e.g., ICO in the UK)

CCPA RIGHTS (California Residents):

  - Right to Know: Request disclosure of categories and specific pieces of
    personal information collected about you
  - Right to Delete: Request deletion of personal information (subject to
    legal exceptions)
  - Right to Opt-Out of Sale: We DO NOT sell your personal information
  - Right to Non-Discrimination: No discriminatory treatment for exercising
    your CCPA rights

To exercise any right: privacy@mifos.org
Response time: 30 days (GDPR) / 45 days (CCPA)
