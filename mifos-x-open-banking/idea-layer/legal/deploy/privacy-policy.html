1. Introduction

Mifos-X Open Banking ("the App") is a Kotlin Multiplatform (KMP) banking application available on Android, iOS, desktop, and web. It connects Consumer users (retail banking customers) and Field Officers (agent banking staff) to financial services powered by the Open Bank Project (OBP) REST API v7.0.0.

We are committed to protecting your personal data and financial privacy. This Privacy Policy explains what data we collect, how we use it, who we share it with, and what rights you have under GDPR, CCPA, and other applicable privacy laws.

Banking-grade privacy: We never sell your data. Financial data is accessed only via your bank's OBP API and is not transmitted to any other party. Crash diagnostics on Android contain no financial data.

3. Data We Collect and Why

3.1 Financial and Account Information

When you authenticate, we access the following financial data via the OBP API on your behalf:

Data TypeOBP API EndpointPurpose
Bank account numbers (masked)/obp/v7.0.0/my/accountsAccount list & balances
Account balances/obp/v7.0.0/accounts/{id}/balancesHome dashboard, detail screens
Transaction history/obp/v7.0.0/accounts/{id}/transactionsTransaction list, spending analysis
Beneficiary details/obp/v7.0.0/.../beneficiariesSend money flows
Payment card info (masked PAN)/obp/v7.0.0/my/cardsCard management
Standing orders/obp/v7.0.0/accounts/{id}/standing-ordersStanding order management
FX rates/obp/v7.0.0/fx/available-currency-iso-codesFX rates screen

Financial data is cached locally in an encrypted Room KMP database for offline display. It is not transmitted to any server other than your bank's OBP API endpoint.

3.4 Field Officer Customer Data

Field Officers performing KYC and customer onboarding collect customer personal data (name, DOB, national ID, address, contact details, KYC documents) which is transmitted to and stored by the OBP API backend. The banking institution is responsible for the lawful basis and retention of these customer records.

7. International Data Transfers

Financial data is transmitted to the OBP API server operated by your banking institution. If that server is outside your country, an international data transfer occurs under the banking institution's legal framework.

Firebase services are provided by Google LLC (USA). Google participates in the EU-US Data Privacy Framework and has Standard Contractual Clauses (SCCs) in place per GDPR Article 46.

8. Security

We implement the following technical safeguards:

  • All network communications use HTTPS / TLS 1.2+
  • OBP session tokens stored in Android Keystore / iOS Secure Enclave encrypted storage
  • Local Room KMP database is encrypted at rest
  • Passwords are never logged, stored on-device, or transmitted to any party other than the OBP login endpoint
  • Firebase crash reports are configured to exclude sensitive financial data fields

10. Children's Privacy

This App is a banking application for adults (18+) and authorized banking professionals. We do not knowingly collect personal data from individuals under 18. Contact privacy@mifos.org immediately if you believe a minor's data has been collected.
