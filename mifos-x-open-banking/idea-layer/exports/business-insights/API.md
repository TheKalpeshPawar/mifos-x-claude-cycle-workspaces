## GET /obp/v5.1.0/my/banks/{bank_id}/accounts/{account_id}/account

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** Accounts
**Trigger:** `loadBusinessAccounts()` — fetched per candidate account to classify scope, because the account-list endpoint returns `product_code: null`

Returns the full directory entry for one account. The `product_code` (CURRENT / SAVINGS / BUSINESS / WALLET) is the discriminator used to restrict the account picker to BUSINESS accounts.

### Path Parameters

| Name       | Type   | Required | Demo Value               | Description                          |
|------------|--------|----------|--------------------------|--------------------------------------|
| bank_id    | String | Yes      | mifos.uk.gb.01           | OBP bank identifier                  |
| account_id | String | Yes      | acc-techstart-gbp-biz-01 | Candidate account being classified   |

### Response Fields

| Field        | Type          | Description                                                       |
|--------------|---------------|-------------------------------------------------------------------|
| label        | String        | Account display label (e.g. "TechStart — Business Current GBP")   |
| product_code | String        | Scope discriminator — BUSINESS accounts are kept for the picker   |
| balance      | AmountOfMoney | Current balance (amount + currency)                               |

### Error Codes

| Code | OBP Message        | UI Handling                                  |
|------|--------------------|----------------------------------------------|
| 401  | USER_NOT_LOGGED_IN | Navigate to login; session expired           |
| 404  | ACCOUNT_NOT_FOUND  | Skip the account from the BUSINESS picker set |

## GET /obp/v6.0.0/my/accounts/{account_id}/transactions

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** Transactions
**Trigger:** `selectAccount()` / `selectPeriod()` — fetches the selected business account's transactions; cash-flow + categorisation run client-side

Fetches transactions for the selected business account. The OBP sandbox caps the result at the 50 newest and ignores date params, so all period filtering and 8-category bucketing happen on-device.

### Path Parameters

| Name       | Type   | Required | Demo Value               | Description                  |
|------------|--------|----------|--------------------------|------------------------------|
| account_id | String | Yes      | acc-techstart-gbp-biz-01 | Selected business account ID |

### Response Fields

| Field        | Type               | Description                                            |
|--------------|--------------------|--------------------------------------------------------|
| transactions | List<Transaction>  | Transaction rows for the account                       |
| details      | TransactionDetails | Per-transaction detail (description, posted, type)     |
| value        | AmountOfMoney      | Signed amount + currency — credits = in, debits = out  |

### Error Codes

| Code | OBP Message        | UI Error Displayed                                            |
|------|--------------------|--------------------------------------------------------------|
| 401  | USER_NOT_LOGGED_IN | Navigate to login; session expired                           |
| 404  | ACCOUNT_NOT_FOUND  | error state: "Could not load business insights"              |
| —    | network / timeout  | error state: "Check your connection and try again." + retry  |

### Client-side Derivation

- **Cash flow:** sum positive `value.amount` → Money In; sum negative → Money Out; Net = In + Out.
- **Categorisation:** debits bucketed into the 8-category taxonomy by description keywords; the **Income** category absorbs credit keywords but is excluded from the expenses-only donut.
- **No budgets:** business accounts are tracked by cash flow only.
