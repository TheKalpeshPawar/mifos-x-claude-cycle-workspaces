## Error Handling

All endpoints follow standard error mapping:
- 401 → Auth error — `TokenExpiredError(recoverable=true)` → Retry button shown
- 403 → Consent withdrawn — `ConsentWithdrawnError(recoverable=false)` → Go Back button shown
- 404 (client) → transactionId absent in list — `TransactionNotFoundError(recoverable=false)` → Go Back button shown
- null (network) → `NetworkError(recoverable=true)` → Retry button shown
