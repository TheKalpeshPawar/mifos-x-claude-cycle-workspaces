### Client-Side Resolution

| Step | Description |
|------|-------------|
| 1. Cache check | Look up `transactions_{accountId}` in-memory cache (TTL 300s) |
| 2. Cache hit | Filter cached `OBTransaction6[]` by `transactionId` — no network call |
| 3. Cache miss | Fetch `GET /accounts/{accountId}/transactions` via ktorfit; store result in cache; filter by transactionId |
| 4. Not found | transactionId absent in the (fresh) result → emit `TransactionNotFoundError` → route to `empty` state |

### Error Mapping

| HTTP / Condition | Error Class | Recoverable | UI State |
|-----------------|-------------|-------------|----------|
| 401 | TokenExpiredError | true | Error state with Retry button |
| 403 | ConsentWithdrawnError | false | Error state with Go Back button only |
| transactionId absent in 200 response | TransactionNotFoundError | false | Empty state with Go Back button |
| Network (IOException) | NetworkError | true | Error state with Retry button |
