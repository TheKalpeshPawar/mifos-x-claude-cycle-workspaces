# API Reference — Transaction Detail
**Feature:** transaction-detail | **Base URL:** https://apisandbox.openbankproject.com

---

## GET /obp/v5.1.0/banks/{bankId}/accounts/{accountId}/owner/transactions/{transactionId}/transaction

Retrieves the full detail of a single transaction including counterparty routing, balance snapshot after transaction, and OBP metadata (narrative, comments, tags).

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** Transactions

### Path Parameters

| Name | Type | Required | Example |
|---|---|---|---|
| bankId | String | Yes | gh.29.uk |
| accountId | String | Yes | acc_checking_primary |
| transactionId | String | Yes | txn_20260525_001 |

### Response Fields

| Field | Type | Description |
|---|---|---|
| id | String | Transaction identifier |
| this_account.id | String | Owning account identifier |
| this_account.account_routings | List\<AccountRouting\> | Owning account routing schemes + addresses |
| other_account.id | String | Counterparty account identifier |
| other_account.holder.name | String | Counterparty display name (e.g. "Tesco PLC") |
| other_account.holder.is_alias | Boolean | Whether counterparty name is anonymised |
| other_account.account_routings | List\<AccountRouting\> | Counterparty routing (IBAN etc.) |
| other_account.metadata.image_url | String? | Merchant logo URL (nullable) |
| details.type | String | Transaction type code (e.g. "SEPA_CREDIT_TRANSFERS") |
| details.description | String | Transaction description / merchant narrative |
| details.posted | String | ISO 8601 posting timestamp (e.g. "2026-05-25T14:32:00.000Z") |
| details.completed | String | ISO 8601 completion timestamp |
| details.new_balance.currency | String | Account currency after transaction |
| details.new_balance.amount | String | Account balance after transaction |
| details.value.currency | String | Transaction currency |
| details.value.amount | String | Signed amount (negative = debit, e.g. "-42.50") |
| metadata.narrative | String? | Free-text narrative (nullable) |
| metadata.comments | List\<Comment\> | OBP comments on this transaction |
| metadata.tags | List\<Tag\> | OBP tags on this transaction |

### Error Codes

| HTTP Code | Message | Resolution |
|---|---|---|
| 401 | Unauthorized — DirectLogin token missing or expired | Re-authenticate via POST /my/logins/direct |
| 404 | Transaction not found | Verify transactionId; it may have been removed from the view |
| 500 | OBP server error | Retry with exponential backoff |
