## GET /obp/v5.1.0/banks/{bankId}/customers/{customerId}

Fetches the full customer record. Used to populate the header, personal info card, address card, relationship manager card, and KYC status banner.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |
| customerId | String | OBP customer identifier |

### Response Fields

| Field | Type | Description |
|---|---|---|
| bank_id | String | Bank identifier |
| customer_id | String | Customer unique identifier |
| customer_number | String | Human-readable customer number |
| legal_name | String | Full legal name |
| mobile_phone_number | String | Primary phone |
| email | String | Email address |
| face_image | FaceImage | Profile image metadata |
| date_of_birth | String | ISO date |
| relationship_status | String | Marital/relationship status |
| dependants | Int | Number of dependants |
| credit_rating | CreditRating | Credit rating object |
| credit_limit | Amount | Credit limit `{currency, amount}` |
| highest_education_attained | String | Education level |
| employment_status | String | Current employment status |
| kyc_status | Boolean | Whether KYC is verified |
| last_ok_date | String | Last successful interaction timestamp |
| title | String | Honorific (Mr, Mrs, Dr, etc.) |
| branch_id | String | Assigned branch |
| name_suffix | String | Suffix (Jr, Sr, etc.) |

### Error Codes

| Code | Meaning |
|---|---|
| 401 | Unauthorized — missing or invalid token |
| 403 | Forbidden — insufficient permissions |
| 404 | Customer not found |
| 500 | Internal server error |

## GET /obp/v5.1.0/banks/{bankId}/customers/{customerId}/accounts

Fetches accounts linked to this customer. Used to populate the quick stats bar (account count, total balance) and the Accounts tab.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |
| customerId | String | OBP customer identifier |

### Response Fields

| Field | Type | Description |
|---|---|---|
| accounts | List\<Account\> | Linked account records |
| id | String | Account unique identifier |
| label | String | Account display name |
| number | String | Account number |
| bank_id | String | Bank identifier |
| account_routings | List\<AccountRouting\> | Routing details (IBAN, etc.) |
| balance | Amount | Current balance `{currency, amount}` |
| account_type | String | Account type (checking, savings, etc.) |

### Error Codes

| Code | Meaning |
|---|---|
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Customer or bank not found |
| 500 | Internal server error |
