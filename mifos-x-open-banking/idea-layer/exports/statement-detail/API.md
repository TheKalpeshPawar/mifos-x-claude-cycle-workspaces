## GET /accounts/{AccountId}/statements/{StatementId}

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| AccountId | string | yes | OBIE AccountId for the authorised account |
| StatementId | string | yes | Statement identifier from OBReadStatement2.Data.Statement[].StatementId |

### Response: OBReadStatement2 (HTTP 200)

**Data path**: `OBReadStatement2.Data.Statement[0]` (single statement by id)

| Field | Type | Notes |
|-------|------|-------|
| StatementId | string | Unique statement identifier |
| StatementReference | string | Human-readable reference (e.g. MAY-2026-STMT); used as top_app_bar_title |
| StartDateTime | string (ISO-8601 UTC) | Statement period start; formatted by ViewModel to "dd MMM yyyy" |
| EndDateTime | string (ISO-8601 UTC) | Statement period end; formatted by ViewModel to "dd MMM yyyy" |
| Type | string | OBIE StatementType enum (e.g. RegularPeriodic) |
| CreationDateTime | string (ISO-8601 UTC) | Timestamp when HSBC generated the statement |
| StatementAmount[] | OBStatementAmount2 | Array of balance entries; each has Type (OpeningBalance / ClosingBalance), CreditDebitIndicator, Amount.Amount, Amount.Currency |
| StatementFee[] | OBStatementFee1 | Array of fee entries; may be empty. Each has Description, Amount.Amount, Amount.Currency |
| StatementInterest[] | OBStatementInterest1 | Array of interest entries; may be empty. Each has Description, CreditDebitIndicator, Amount.Amount, Amount.Currency |

**Permission note**: `ReadStatementsDetail` is required (not just `ReadStatements`) to receive `StatementAmount`, `StatementFee`, and `StatementInterest` arrays.

## GET /accounts/{AccountId}/statements/{StatementId}/transactions

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|

### Response: OBReadTransaction6 (HTTP 200)

**Data path**: `OBReadTransaction6.Data.Transaction[]`

| Field | Type | Notes |
|-------|------|-------|
| TransactionId | string | Passed as route param to transaction-detail |
| AccountId | string | Passed as route param to transaction-detail |
| BookingDateTime | string (ISO-8601 UTC) | Displayed as overline in statement_txn_row |
| TransactionInformation | string | Merchant/narrative text; displayed as supporting_text |
| CreditDebitIndicator | string | Credit (tertiary color) or Debit (error color) |
| Amount.Amount | string (decimal) | Transaction amount |
| Amount.Currency | string (ISO 4217) | Currency code (e.g. GBP) |

**Permission note**: `ReadTransactions` is required in addition to `ReadStatementsDetail`. The endpoint is called in parallel with the statement endpoint.

**Empty response**: A successful HTTP 200 with an empty `Data.Transaction[]` array is a valid OBIE response. The ViewModel transitions to `StatementDetailUiState.Empty` in this case — it does not emit an error.

## GET /accounts/{AccountId}/statements/{StatementId}/file

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| AccountId | string | yes | OBIE AccountId |
| StatementId | string | yes | Statement identifier |

### Request Headers

| Header | Value | Required |
|--------|-------|----------|
| Accept | `application/pdf` | yes |

### Response

Binary PDF stream. Response DTO is null — bytes are passed directly to the platform share/save sheet via `ktor-client-download`.

- **On success**: `downloadState` → `Downloaded(uri)`; platform share/save sheet presented with PDF binary; success snackbar displayed
- **On HTTP 404**: `downloadState` → `DownloadError(message)`; error snackbar displayed (PDF not yet generated by HSBC)
- **On network error**: `downloadState` → `DownloadError(message)`; error snackbar displayed

### Error Mapping

| HTTP | UI Behaviour | Retry |
|------|--------------|-------|
| 404 | `downloadState = DownloadError("Download failed")` — error snackbar displayed; download_pdf_button re-enabled | manual |
| Network | `downloadState = DownloadError("Download failed")` — error snackbar displayed | manual |

### Consumers

| Consumer | Usage |
|----------|-------|
| statement-detail | `download_pdf_button` — triggered per-statement by the user |
| statements | `download_statement_button` per-row download icon (shared PDF/CSV download path; Accept header broadened to `application/pdf, text/csv` in that screen) |
