- **DownloadState**: `DownloadState` — sealed class
  - `Idle`
  - `Downloading`
  - `Downloaded(uri: Uri)`
  - `DownloadError(message: String)`
- **Errors**:
  - `HTTP_401` — Session expired. Please re-authenticate. (retry=true)
  - `HTTP_403` — Consent does not include ReadStatements. (retry=true)
  - `HTTP_404` — Statement not found. (retry=true)
  - `HTTP_404_FILE` — Statement PDF file not yet generated by HSBC. (retry=false)
  - `NETWORK_ERROR` — Device offline or AIS endpoint unreachable. (retry=true)
- **Events**: downloadStatePdf success → platform share/save sheet; snackbar on Downloaded/DownloadError
- **Actions**:
  - `statementDetailLoad(accountId: String, statementId: String)` — parallel GET statement + GET statement-txns
  - `downloadStatementPdf(accountId: String, statementId: String)` — GET statement-file (application/pdf)
  - `retryLoad(accountId: String, statementId: String)` — delegates to statementDetailLoad
- **DI**: ktorfit (rest-client), ktor-client (file-download)
