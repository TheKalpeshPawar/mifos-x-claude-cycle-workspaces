# API Reference — Settings

| Field    | Value                                       |

| Feature  | settings                                    |

No direct API calls — data passed via navigation parameters.

The Settings screen reads and writes all preference state from/to the local `SettingsRepository`, which wraps Jetpack DataStore (Proto or Preferences). No HTTP requests are issued from this screen.

**Local data flows:**

| Preference                  | Platform Manager   | Storage             |
|-----------------------------|--------------------|---------------------|
| isDarkModeEnabled           | LocaleManager      | DataStore           |
| selectedLanguage            | LocaleManager      | DataStore           |
| isPushNotificationsEnabled  | NotificationManager| DataStore           |
| isTransactionAlertsEnabled  | NotificationManager| DataStore           |
| isBiometricLoginEnabled     | BiometricManager   | DataStore           |
| isBiometricAvailableOnDevice| BiometricManager   | Runtime device query|
| appVersion                  | —                  | BuildConfig.VERSION_NAME |

The `nav_to_about` navigation passes no parameters — the About screen loads static content from app resources.
