## Overview

The Customer Messages screen is the field officer's messaging center, displaying a list of conversation threads with their assigned customers. Each thread row shows the customer's initials avatar, name, message preview, and relative timestamp, with unread threads visually distinguished by a filled background and unread dot indicator. An extended FAB opens a compose bottom sheet where the officer can select a customer, set a subject, and write a message. The screen supports both inbound thread viewing and outbound message composition via the OBP customer messages API.
