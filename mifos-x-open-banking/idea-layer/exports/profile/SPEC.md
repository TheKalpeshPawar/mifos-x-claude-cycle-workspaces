| Profile | ProfileViewModel | loading, content, content_expiring, confirm_sign_out, error, empty | Fetches PSU identity via hsbc-obie-ais-v4.0:party using ktorfit then merges it with the cached active-consent record (status, expiry, permissions list). Derives content_expiring state client-side when consent.days_remaining ≤7. Displays name, email, mobile, residential address, consent status, expiry, and the full set of granted OBIE Read permissions. Sign-out clears access token, refresh token, and ConsentId from encrypted storage and navigates to login. | Decision | Condition | True Path | False Path | Implementation |

| Empty party response | HTTP 200 but Data.Party[] is empty | emit empty state (EC-PROF-006); account_circle_off icon; no Retry | proceed to content or content_expiring | loadProfile() post-response check |
| Consent expiry | consent.days_remaining ≤ 7 | emit content_expiring; show warning banner + Renew Consent CTA | emit content | loadProfile post-load check |
