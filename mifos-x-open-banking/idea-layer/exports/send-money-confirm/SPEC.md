## Overview

The Confirm Payment screen presents a read-only summary of all payment details collected on the Send Money screen, requiring explicit user confirmation before submitting the transaction request to OBP. The screen shows the recipient, IBAN, source account, reference, fee breakdown, and total, with an optional date scheduling control. A two-button layout gives users a final gate to either confirm the payment or return to edit.

## States

| State ID | Trigger | Description |
|---|---|---|
| review | Screen load from send-money | Full detail summary shown, both buttons enabled |
| submitting | User taps "Confirm & Send" | Confirm button loading, both buttons disabled, linear progress |
| success | Payment API returns 2xx | Success snackbar "Payment of £500.00 sent to John Smith", navigate to home |
| error | Payment API returns error | Error banner shown, confirm re-enabled for retry |
