## GET /obp/v5.1.0/banks/{bankId}/account-applications/{applicationId}

**Auth:** DirectLogin
**Tag:** Account-Applications
**Trigger:** Screen entry — loads full application record in parallel with KYC status

### Path Parameters

| Name          | Type   | Description               |
|---------------|--------|---------------------------|
| bankId        | String | OBP bank identifier       |
| applicationId | String | Account application UUID  |

### Response Fields

| Field                   | Type    | Description                                      |
|-------------------------|---------|--------------------------------------------------|
| account_application_id  | String  | Application UUID                                 |
| product_code            | String  | Banking product code (e.g. "SAVINGS_KCB_001")   |
| user.user_id            | String  | OBP user UUID of the applicant                   |
| user.username           | String  | OBP username (e.g. "john.mwangi")               |
| customer.customer_id    | String  | Customer UUID                                    |
| customer.customer_number| String  | Bank-assigned customer number                    |
| date_of_application     | String  | ISO-8601 submission timestamp (e.g. "2026-05-20T10:30:00Z") |
| date_last_modified      | String  | ISO-8601 last modification timestamp             |
| status                  | String  | PENDING \| APPROVED \| REJECTED                 |
| account_routing         | Object  | scheme + address (populated post-approval)       |

### Error Codes

| Code | Message               | Description                        |
|------|-----------------------|------------------------------------|
| 400  | BAD_REQUEST           | Malformed request parameters       |
| 401  | UNAUTHORIZED          | Invalid or expired DirectLogin token |
| 404  | APPLICATION_NOT_FOUND | No application matching this ID    |

## PUT /obp/v5.1.0/banks/{bankId}/account-applications/{applicationId}

**Auth:** DirectLogin
**Tag:** Account-Applications
**Trigger:** `approve_application_button` tap (status: APPROVED) or `reject_application_button` tap (status: REJECTED)

### Path Parameters

| Name          | Type   | Description               |
|---------------|--------|---------------------------|
| bankId        | String | OBP bank identifier       |
| applicationId | String | Account application UUID  |

### Request Body

| Field  | Type   | Values                | Description                 |
|--------|--------|-----------------------|-----------------------------|
| status | String | APPROVED \| REJECTED  | Decision on the application |

### Response Fields

| Field                  | Type   | Description                           |
|------------------------|--------|---------------------------------------|
| account_application_id | String | Application UUID                      |
| status                 | String | Updated status (APPROVED or REJECTED) |
| date_last_modified     | String | ISO-8601 timestamp of decision        |

### Error Codes

| Code | Message               | Description                              |
|------|-----------------------|------------------------------------------|
| 400  | VALIDATION_FAILED     | Invalid status value in request body     |
| 401  | UNAUTHORIZED          | Invalid or expired DirectLogin token     |
| 404  | APPLICATION_NOT_FOUND | No application matching this ID          |
