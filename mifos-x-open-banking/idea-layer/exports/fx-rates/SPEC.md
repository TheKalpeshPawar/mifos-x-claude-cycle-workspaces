## Overview

The Exchange Rates screen provides consumers with live OBP-sourced currency exchange rates and an interactive converter tool. Users can enter an amount, select source and destination currencies, and immediately see the converted result alongside a "Send this amount" CTA that routes to the send-money flow. A curated list of popular currency pairs (GBP/EUR, GBP/USD, GBP/JPY, EUR/USD, USD/INR, EUR/GBP) is displayed below the converter with real-time rate values and daily change indicators, allowing users to tap any pair to pre-populate the converter.
