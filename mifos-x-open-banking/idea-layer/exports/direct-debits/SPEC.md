## Purpose

Calls GET `/accounts/{AccountId}/direct-debits` via Ktorfit to retrieve `OBReadDirectDebit2`. Maps each `Data.DirectDebit` using `Name`, `DirectDebitStatusCode`, `PreviousPaymentAmount`, `PreviousPaymentDateTime`, and `MandateIdentification`. ViewModel derives `status_variant` (Active → primary badge, Inactive → outline badge), computes `activeCount` / `inactiveCount` summary, sorts the list Active-first then Inactive, and maps HTTP error codes to typed user-facing messages (`TokenExpired` 401, `ConsentRevoked` 403, `RateLimited` 429, `NetworkError`). Read-only under AISP `ReadDirectDebits` consent; retry is suppressed for 403 ConsentRevoked.
