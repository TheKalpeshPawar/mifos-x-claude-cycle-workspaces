## Create Direct Debit Mandate

**POST** `/obp/v4.0.0/banks/{bankId}/accounts/{accountId}/owner/direct-debit`

Creates a new direct debit mandate authorising a payee to collect from the account. This is the primary write API for this screen. OBP v4.0.0 does not expose a dedicated list endpoint — the content list is populated from bank-specific mandate APIs or filtered transaction history.

**Auth:** DirectLogin

**Path Parameters:**

| Param | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier (e.g., "gb.mifos") |
| accountId | String | Account to be debited |

**Request Fields:**

| Field | Type | Required | Description |
|---|---|---|---|
| start_date | String | Yes | ISO 8601 mandate start date (YYYY-MM-DD) |
| end_date | String | No | ISO 8601 mandate end date; omit for indefinite |
| to | DirectDebitCounterparty | Yes | Payee details object |
| amount_value | String | Yes | Per-collection amount (decimal string) |
| amount_currency | String | Yes | ISO 4217 currency code |

**Request Body:**

```json
{
  "start_date": "2026-06-01",
  "end_date": "2027-05-31",
  "to": {
    "counterparty_id": "hackney-council-counterparty-uuid"
  },
  "amount_value": "148.00",
  "amount_currency": "GBP"
}
```

**Response Fields:**

| Field | Type | Description |
|---|---|---|
| direct_debit_id | String | Unique mandate identifier |
| bank_id | String | Bank identifier |
| account_id | String | Debited account identifier |
| counterparty_id | String | Payee counterparty reference |
| amount_value | String | Authorised collection amount |
| amount_currency | String | Currency code |
| start_date | String | Mandate effective from date |
| end_date | String | Mandate expires on date (null if indefinite) |
| active | Boolean | true if mandate is currently active |

**Sample Response:**

```json
{
  "direct_debit_id": "dd-council-tax-uuid-001",
  "bank_id": "gb.mifos",
  "account_id": "acc-primary-0130",
  "counterparty_id": "hackney-council-counterparty-uuid",
  "amount_value": "148.00",
  "amount_currency": "GBP",
  "start_date": "2026-06-01",
  "end_date": "2027-05-31",
  "active": true
}
```

**Error Codes:**

## Implementation Notes

**List population:** Use `GET /obp/v4.0.0/banks/{bankId}/accounts/{accountId}/owner/transactions` and filter by `details.type: "DirectDebit"` for display. Alternatively, if the bank provides a mandate list extension endpoint, prefer that.

**Cancellation:** Direct debit cancellation is not part of OBP standard. Handled via bank-specific endpoint or by contacting the payee directly. The `view_direct_debit` action opens a detail sheet that surfaces the mandate reference for manual cancellation via the bank.

**Navigation back:** `navigate_back` targets the `accounts` screen (not home), supporting the "payments" section sub-navigation pattern.
