## GET /accounts/{AccountId}/direct-debits

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| AccountId | string | yes | OBIE AccountId from GET /accounts. ReadDirectDebits must be declared in the AIS consent permissions list (POST /account-access-consents). |

### Response: OBReadDirectDebit2 (HTTP 200)

**Data path**: `OBReadDirectDebit2.Data.DirectDebit[]`

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| DirectDebitId | string | yes | Unique mandate identifier |
| AccountId | string | yes | Parent account |
| Name | string | yes | Originator / payee name |
| DirectDebitStatusCode | OBExternalDirectDebitStatus1Code | yes | Active \| Inactive |
| MandateIdentification | string | no | Mandate reference number (displayed in card) |
| PreviousPaymentAmount.Amount | string | no | Last collected payment amount (decimal string) |
| PreviousPaymentAmount.Currency | string | no | ISO 4217 currency code |
| PreviousPaymentDateTime | string (ISO-8601) | no | Date/time of last collection; formatted locale-aware by ViewModel |

No pagination — OBIE AIS v4.0 direct-debits endpoint returns the complete list in a single response. Inactive mandates are included alongside active.
