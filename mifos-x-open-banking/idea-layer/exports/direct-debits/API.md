## Error Handling

All endpoints follow standard error mapping:
- 400 → Bad request — malformed AccountId
- 401 → Auth error — TokenExpired; isRetriable=true; surface Retry CTA
- 403 → Forbidden — ReadDirectDebits not in consent (ConsentRevoked); isRetriable=false; hide Retry CTA; user must re-authorise via consent-list
- 429 → RateLimited — isRetriable=true; surface Retry CTA
- 500 → Server error — treated as NetworkError; isRetriable=true

## Notes
