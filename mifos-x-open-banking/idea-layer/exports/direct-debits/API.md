## GET /accounts/{AccountId}/direct-debits

Returns the full direct debit mandate list for the specified account. The `ReadDirectDebits` permission must be declared in the AIS consent (`POST /account-access-consents`) before this endpoint can be called. No pagination — OBIE AIS v4.0 returns the complete list in a single response. Inactive mandates are included alongside active ones.

## Auth/Consent Notes

- Authentication: OAuth2 FAPI-1.0 **PSU bearer token** obtained during the consent-callback flow and stored in EncryptedSharedPreferences.
- Permission gate: `ReadDirectDebits` must be included in `Data.Permissions[]` of the active consent. If the permission is absent, the HSBC sandbox returns HTTP 403, which the ViewModel maps to `ConsentRevoked` (non-retriable — the PSU must re-authorise consent via the FAPI flow to add this permission).
- The 403 ConsentRevoked case intentionally **hides the retry button** because retrying the same request will always fail until the consent is re-established.
- A `200 + empty Data.DirectDebit[]` is not treated as an error — it means the account has no registered mandates, which is a valid state shown as the empty screen.
