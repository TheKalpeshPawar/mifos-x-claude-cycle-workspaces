## GET /obp/v6.0.0/signal/channels

**Tag:** Signal
**Purpose:** List all real-time push notification channels available for the authenticated user. Channels are the OBP Signal delivery mechanism for payment events, budget alerts, and direct debit reminders displayed in this screen.

### Response Fields

| Field | Type | Description |
|---|---|---|
| channels | List\<SignalChannel\> | Array of notification channel objects |
| channel_id | String | Unique channel identifier |
| name | String | Channel name (e.g. "payment_received", "budget_alert") |
| description | String | Human-readable description of what events this channel delivers |
| created_at | String | ISO 8601 timestamp when the channel was created |

### Error Codes

| Code | Meaning |
|---|---|
| 401 | USER_NOT_LOGGED_IN — DirectLogin token missing or expired |
| 403 | INSUFFICIENT_AUTHORISATION — token lacks Signal scope |

---

**Note:** The notification feed shown in the UI (payment received, direct debit reminder, budget alert) is assembled client-side by combining Signal channel data with local notification history tracked by the `NotificationRepository`. Individual notification items — including read state, body text, and deep-link targets — are stored locally after being received via push (Firebase Cloud Messaging) and do not map directly to a single OBP read endpoint.
