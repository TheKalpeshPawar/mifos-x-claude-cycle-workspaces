## GET /obp/v6.0.0/signal/channels

**Auth:** DirectLogin
**Tag:** Signal
**Trigger:** `loadDashboardData()` / `SignalRepository.fetchChannels()` on screen entry — configures FCM push notification subscriptions for the authenticated user.

Lists all available real-time push notification channels (FCM). The `NotificationsViewModel` passes the channel list to `SignalRepository` to register the device's FCM token against the active channels. This endpoint does not return the notification history itself — the notification list is managed client-side by `NotificationRepository`.

### Response Fields

| Field                      | Type                    | Description                                                          |
|----------------------------|-------------------------|----------------------------------------------------------------------|
| channels                   | List\<SignalChannel\>   | Array of available notification channel objects                      |
| channels[].channel_id      | String                  | Unique channel identifier — used as subscription key                 |
| channels[].name            | String                  | Human-readable channel name displayed in settings                    |
| channels[].description     | String                  | Full description of what events trigger this channel                 |
| channels[].created_at      | String (ISO-8601)       | Channel creation timestamp                                           |
