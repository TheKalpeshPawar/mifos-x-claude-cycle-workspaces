## Endpoints

(none — this screen performs no network calls; navigation/redirect only)

`PaymentDeclinedScreen` is a stateless, args-driven terminal screen. All data (amount, payee, decline reason) arrives as navigation arguments resolved upstream by `auth-callback` from the following sources:

- The OAuth2 callback `error` param (e.g. `access_denied`) when the PSU declines at HSBC
- The payment consent `Data.Status` = `RJCT` and `Data.StatusReason` from `GET /obie/open-banking/v4.0/pisp/domestic-payment-consents/{ConsentId}`
- A rejected response from `POST /obie/open-banking/v4.0/pisp/domestic-payments`

SCA is performed at HSBC during the authorise redirect — this screen replaces the obsolete OBP in-app `sca-challenge` error path. No OBIE API is invoked here.
