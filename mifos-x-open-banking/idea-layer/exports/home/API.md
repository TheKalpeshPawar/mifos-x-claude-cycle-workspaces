## Overview

Home makes **3 OBIE AIS calls** on each mount/reload. All require a valid FAPI 1.0 PSU bearer token and corresponding AIS consent permissions. The first call (`/accounts`) is sequential; the next two (`/balances`, `/transactions`) are fired in parallel using `coroutineScope { async { ... }.await() }`.

| ID | Method | Path | Permission | Call Order |
|----|--------|------|------------|------------|
| accounts-list | GET | /accounts | ReadAccountsDetail | Sequential (first on mount) |
| selected-account-balances | GET | /accounts/{AccountId}/balances | ReadBalances | Parallel (after switcher) |
| recent-transactions | GET | /accounts/{AccountId}/transactions | ReadTransactionsDetail | Parallel (after switcher) |

```kotlin

    balance = balanceDef.await()
    txList  = txDef.await()
}
```

## GET /accounts

Retrieves all accounts authorised under the current OBIE consent. Authenticated with a **PSU bearer token**. Populates the account-switcher chip row and establishes `selectedAccountId` (default: first account in list).

### Response: OBReadAccount6 (HTTP 200)

**Data path**: `OBReadAccount6.Data.Account[]`

| Field | Type | Used for |
|-------|------|---------|
| Data.Account[*].AccountId | string | account_chip key; balance + tx call params; selectedAccountId |
| Data.Account[*].Nickname | string | account_chip label; hero_nickname |
| Data.Account[*].AccountSubType | string | hero_account_subtype (e.g. 'CurrentAccount') |
| Data.Account[*].Account[0].Identification | string | hero_identification (masked sort-code + account number) |

**State routing:** `Data.Account[]` empty → `HomeUiState.Empty(reason = no_accounts)`.

### Error Codes

| HTTP | Cause | Recoverable | UI Outcome |
|------|-------|-------------|------------|
| 401 | PSU token expired (TokenExpiredError) | true | Error state; Retry CTA + navigate-to-login recovery |
| 403 | ReadAccountsDetail not in consent (ConsentScopeError) | false | Error state; no Retry button; direct PSU to consent-list |
| 429 | HSBC rate-limit (RateLimitError) | true | Error state; exponential back-off + Retry CTA |
| Network | IOException / timeout (NetworkError) | true | Error state; Retry CTA |

## GET /accounts/{AccountId}/balances

Retrieves the balance list for the selected account. Fired in parallel with `/transactions` using `async { ... }`. The ViewModel selects the best available balance type: `InterimAvailable` → `InterimBooked` → `OpeningBooked`.

### Path Parameters

| Param | Type | Notes |
|-------|------|-------|
| AccountId | string | Currently selected account's AccountId; passed by ViewModel |

### Response: OBReadBalance1 (HTTP 200)

**Data path**: `OBReadBalance1.Data.Balance[]`

| Field | Type | Used for |
|-------|------|---------|
| Data.Balance[*].Type | OBBalanceType1Code | Balance preference selection: InterimAvailable → InterimBooked → OpeningBooked |
| Data.Balance[*].Amount.Amount | string | hero_balance (displaySmall), hero_available_amount (bodySmall) |
| Data.Balance[*].Amount.Currency | string | Balance display; GBP formatting |
| Data.Balance[*].CreditDebitIndicator | string | Colour logic (Debit credit card balance → not error colour) |

### Balance Preference Order

| Priority | Type | Component |
|----------|------|-----------|
| 1 | InterimAvailable | hero_balance (hero primary) + hero_available_amount (secondary) |
| 2 | InterimBooked | fallback when InterimAvailable absent |
| 3 | OpeningBooked | last resort |

### Error Codes

| HTTP | Cause | Recoverable | UI Outcome |
|------|-------|-------------|------------|
| 401 | PSU token expired | true | Error state; Retry CTA |
| 403 | ReadBalances not in consent | false | Error state; no Retry button |
| 404 | AccountId stale (consent revoked mid-session) | true | Clear selected account; reload /accounts |

## GET /accounts/{AccountId}/transactions

Retrieves recent transactions for the selected account. Fired in parallel with `/balances`. Client-side: filter `Status=Booked`, sort descending by `BookingDateTime`, take first 5. Query scoped to last 30 days via `fromBookingDateTime`.

### Path Parameters

| Param | Type | Notes |
|-------|------|-------|
| AccountId | string | Currently selected account's AccountId |

### Query Parameters

| Param | Type | Notes |
|-------|------|-------|
| fromBookingDateTime | ISO-8601 datetime | 30 days before today — limits result set to recent activity |

### Response: OBReadTransaction6 (HTTP 200)

**Data path**: `OBReadTransaction6.Data.Transaction[]`

| Field | Type | Used for |
|-------|------|---------|
| Data.Transaction[*].TransactionId | string | recent_tx_row on_click param (navigate to transaction-detail) |
| Data.Transaction[*].AccountId | string | recent_tx_row on_click param |
| Data.Transaction[*].TransactionInformation | string | tx_description (bodyMedium, max 1 line, ellipsis) |
| Data.Transaction[*].BookingDateTime | ISO-8601 datetime | tx_date (formatted 'dd MMM'); sort key |
| Data.Transaction[*].Amount.Amount | string | tx_amount (bodyMedium) |
| Data.Transaction[*].CreditDebitIndicator | string | tx_amount colour: Debit→error (#BA1A1A), Credit→primary (#266489) |
| Data.Transaction[*].Status | string | Filter: Booked only; Pending excluded from home preview |
| Data.Transaction[*].ProprietaryBankTransactionCode.Code | string | tx_category_icon lookup; fallback to MerchantCategoryCode |

**Client-side processing:** Filter `Status=Booked` → sort descending by `BookingDateTime` → take first 5.

### Error Codes

| HTTP | Cause | Recoverable | UI Outcome |
|------|-------|-------------|------------|
| 401 | PSU token expired | true | Error state; Retry CTA |
| 403 | ReadTransactionsDetail not in consent | false | Error state; no Retry button |
| 429 | Rate-limit exceeded | true | Recoverable error state; Retry CTA |

## Spending Snapshot — Not an API Call

The `spending_snapshot_card` data (`spendThisMonth`, `topCategoryName`) is derived from **cached Room DB PFM data** — no additional API call is made on home mount. The Room data is populated and refreshed by the `transactions` screen on each visit. If the Room cache is empty, `spendThisMonth` and `topCategoryName` are empty strings and the spending snapshot card renders with placeholder-safe empty-string bindings.

## Auth/Consent Notes

- All 3 endpoints use **PSU bearer token** (FAPI 1.0 Advanced mTLS) stored in EncryptedSharedPreferences.
- Three OBIE permissions required in the active consent: `ReadAccountsDetail`, `ReadBalances`, `ReadTransactionsDetail`. Missing any permission returns HTTP 403 (ConsentScopeError, non-recoverable on home screen).
- Parallel dispatch (`async/awaitAll`) means a 401 on either `/balances` or `/transactions` promotes the entire home screen to an error state regardless of which call failed.
- `selectedAccountId` is persisted in **DataStore** — survives process death, device restart, and app backgrounding.
