## Overview

Home makes **3 OBIE AIS calls** on each mount/reload. All require a valid FAPI 1.0 bearer token and corresponding AIS consent permissions.

| Call | Method | Path | Permission | Order |
|---|---|---|---|---|
| Account switcher list | GET | `/accounts` | ReadAccountsDetail | First (sequential) |
| Selected account balances | GET | `/accounts/{AccountId}/balances` | ReadBalances | Parallel (after switcher) |
| Recent transactions | GET | `/accounts/{AccountId}/transactions` | ReadTransactionsDetail | Parallel (after switcher) |

```kotlin
// Load sequence:
val accounts = apiService.getAccounts()          // → populate switcher + select first account
coroutineScope {
    val balanceDef = async { apiService.getBalances(selectedAccountId) }
    val txDef = async { apiService.getTransactions(selectedAccountId, limit = 5) }
    balance = balanceDef.await()
    txList  = txDef.await()
}
```

### Response Fields Used by UI

| Field | Component | Notes |
|---|---|---|
| `Data.Account[*].AccountId` | `account_switcher` chip key; balance/tx call params | Drives account selection |
| `Data.Account[*].Nickname` | `account_chip` label; `hero_nickname` | Display name |
| `Data.Account[*].AccountSubType` | `hero_account_subtype` | e.g. "CurrentAccount", "Savings" |
| `Data.Account[*].Account[0].Identification` | `hero_identification` | Masked sort-code + account number |

**State routing:** `Data.Account[]` empty → `HomeUiState.Empty(reason = no_accounts)`.

### Cache Behaviour

Results cached in memory (5-min TTL). On account-switcher tap or app resume, cache is invalidated and `/accounts` is re-fetched.

### Error Codes

| HTTP | Cause | Recovery |
|---|---|---|
| 401 | Access token expired | Clear token store → navigate to login |
| 403 | ReadAccountsDetail not in consent | Non-recoverable; navigate to consent-list |
| 429 | HSBC rate-limit exceeded | Exponential back-off + Retry CTA |
| 503 | HSBC sandbox unavailable | Retry CTA after brief delay |

## Endpoint 2 — Selected Account Balances

```
GET /accounts/{AccountId}/balances

Auth:        Bearer {access_token}   (FAPI 1.0 Advanced)
Accept:      application/json
```

### Path Parameters

| Param | Type | Required | Description |

| `AccountId` | string | Yes | Currently selected account's AccountId |

### Response Fields Used by UI

| Field | Component | Notes |
|---|---|---|
| `Data.Balance` where `Type=InterimAvailable` | `hero_balance` (displaySmall) | Primary hero balance; fallback: InterimBooked → OpeningBooked |
| `Data.Balance` (2nd-best type) | `hero_available_amount` (bodySmall) | "Available" label value |
| `Amount.Currency` | Hero card (multi-currency) | Displayed as-is; no GBP conversion for GlobalWallet |
| `CreditDebitIndicator` | Colour logic | CreditCard + Debit → `error` colour on hero balance |

### Balance Preference Order

1. `InterimAvailable` (hero + available)
2. `InterimBooked` (fallback)
3. `OpeningBooked` (last resort)

### Error Codes

| HTTP | Cause | Recovery |
|---|---|---|
| 401 | Access token expired | Error state; navigate_to_login recovery |
| 403 | ReadBalances not in consent | Non-recoverable; direct PSU to consent-list |
| 404 | AccountId stale (consent revoked mid-session) | Clear selected account; reload /accounts |

## Endpoint 3 — Recent Transactions

```
GET /accounts/{AccountId}/transactions

Auth:        Bearer {access_token}   (FAPI 1.0 Advanced)
Accept:      application/json
```

### Path Parameters

| Param | Type | Required | Description |
|---|---|---|---|
| `AccountId` | string | Yes | Currently selected account's AccountId |

### Query Parameters

| Param | Type | Required | Description |
|---|---|---|---|
| `fromBookingDateTime` | string (ISO-8601) | Yes | 30 days before today — limits result set to recent activity |

### Response — OBReadTransaction6

```json
{
  "Data": {
    "Transaction": [
      {
        "AccountId": "40051512345678",
        "TransactionId": "TX001",
        "CreditDebitIndicator": "Debit",
        "Status": "Booked",
        "BookingDateTime": "2026-07-14T09:30:00Z",
        "Amount": { "Amount": "45.20", "Currency": "GBP" },
        "TransactionInformation": "TESCO STORES",
        "ProprietaryBankTransactionCode": { "Code": "SUPERMARKET" }
      }
    ]
  },
  "Links": {},
  "Meta": {}
}
```

### Response Fields Used by UI

| Field | Component | Notes |
|---|---|---|
| `Data.Transaction[*].TransactionInformation` | `tx_description` (bodyMedium, max 1 line, ellipsis) | Merchant / payee name |
| `Data.Transaction[*].BookingDateTime` | `tx_date` (bodySmall) | Formatted as "dd MMM" e.g. "14 Jul" |
| `Data.Transaction[*].Amount.Amount` | `tx_amount` (bodyMedium) | Signed decimal |
| `Data.Transaction[*].CreditDebitIndicator` | `tx_amount` colour | Debit → error #BA1A1A; Credit → primary #266489 |
| `Data.Transaction[*].ProprietaryBankTransactionCode.Code` | `tx_category_icon` | Drives icon lookup; fallback to MerchantCategoryCode |
| `Data.Transaction[*].TransactionId` | Transaction row on-click param | Routes to transaction-detail |

**Client-side processing:** Only the 5 most-recent `Status=Booked` transactions are displayed (sort descending by `BookingDateTime`, client-side slice). Pending transactions excluded from home preview.

### Error Codes

| HTTP | Cause | Recovery |
|---|---|---|
| 401 | Access token expired | Error state; navigate_to_login |
| 403 | ReadTransactionsDetail not in consent | Non-recoverable; surface advisory in recent_transactions section |
| 429 | Rate-limit exceeded | Recoverable; Retry CTA |

## Spending Snapshot — Not an API Call

The `spending_snapshot_card` data (`spendThisMonth`, `topCategoryName`) is derived from **cached Room DB PFM data** — no additional API call is made on home mount. The Room data is populated and refreshed by the `transactions` screen on each visit.
