## Notes

- `getAccounts` result cached in-memory to avoid redundant round-trips on back navigation.
- `getBalances` and `getTransactions` are fetched in parallel via `coroutineScope { async/await }`.
- Only top 5 Booked transactions (sorted descending by BookingDateTime) are displayed; Pending excluded from home preview.
- Category icon derived from ProprietaryBankTransactionCode.Code or MerchantCategoryCode.

## Error Handling

All endpoints follow standard error mapping:
- 401 → Auth error — EC-HOME-001; navigate to login; recoverable=true with Retry
- 403 → Forbidden — EC-HOME-002 (ReadAccountsDetail/ReadBalances absent); recoverable=false; userMessage directs to consent-list
- 404 → AccountId stale — reload /accounts; clear selected account
- 422 → Validation error
- 429 → Rate-limit — EC-HOME-003; exponential back-off + Retry CTA; recoverable=true
- 500/503 → Server error — EC-HOME-006; Retry CTA; recoverable=true
