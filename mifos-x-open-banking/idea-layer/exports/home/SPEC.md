**Description:** Landing screen displaying the currently selected account with a hero balance card (InterimAvailable balance, account nickname, identifier), a quick-action row (Transactions, Statements, Manage Consents; Pay disabled/planned PISP), a recent transactions preview (5 most-recent Booked transactions with debit/credit colour coding), and a spending snapshot card (total spend this month + top category from cached PFM Room data — **tapping routes to `pfm-dashboard`**). An account-switcher chip strip at top drives state reload for a different `AccountId`. Aggregates three AIS endpoints in parallel: GET /accounts (switcher), GET /accounts/{id}/balances, and GET /accounts/{id}/transactions (recent 5). `selectedAccountId` persists in DataStore across app restarts.

```kotlin
// UiState ∈ { Loading, Content, Empty(reason), Error(code, message, recoverable) }
// reason ∈ { no_accounts, no_consent }
```

**Balance preference order:** InterimAvailable → InterimBooked → OpeningBooked.

**Persistence:** `selectedAccountId` written to DataStore; default = first account in `Data.Account[]`.

**PFM spending snapshot:** derived from cached Room DB transaction data — no extra API call on home mount.

**ViewModel Actions:**

| Action | Signature | Side Effect |
|---|---|---|
| `loadHome` | `fun loadHome()` | GET /accounts → populate switcher; parallel GET /accounts/{id}/balances + GET /accounts/{id}/transactions?limit=5 |

| `retryLoad` | `fun retryLoad()` | uiState → Loading; re-invokes loadHome() |
| `navigateToAccountDetail` | `fun navigateToAccountDetail(accountId: String)` | Emit NavEvent.ToAccountDetail(accountId) |

## 6. API Dependencies

| Endpoint ID | Method | Path | Auth | Permission | Parallelism |
|---|---|---|---|---|---|
| `accounts-list` | GET | `/accounts` | Bearer (FAPI 1.0) | ReadAccountsDetail | Sequential (first call on mount) |

```kotlin
    val txDef = async { apiService.getTransactions(selectedAccountId, limit = 5) }
```

## 7. Error Cases

| Error ID | Trigger | Recoverable | Handling |
|---|---|---|---|
| EC-HOME-001 | 401 from /balances or /transactions — token expired | true | Error state; userMessage "Your session has expired."; navigate_to_login recovery |
| EC-HOME-002 | 403 — ReadAccountsDetail / ReadBalances not in consent | false | Error state; direct PSU to consent-list |
| EC-HOME-003 | 429 rate-limit from HSBC | true | Error state; exponential back-off + Retry CTA |
| EC-HOME-004 | Empty Data.Account[] from /accounts | — | Empty state (reason: no_accounts); CTA → login/consent |
| EC-HOME-005 | No active consent | — | Empty state (reason: no_consent); CTA → login |
| EC-HOME-006 | Network error (no connectivity) | true | Error state; Retry CTA |
