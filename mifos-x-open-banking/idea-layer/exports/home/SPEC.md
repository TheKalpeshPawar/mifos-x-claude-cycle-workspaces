## Purpose

Aggregates selected-account data by firing GET `/accounts` (`hsbc-obie-ais-v4.0:accounts`) to populate the account-switcher list, then in a `coroutineScope async/awaitAll` fetches GET `/accounts/{AccountId}/balances` (`hsbc-obie-ais-v4.0:balances`) and GET `/accounts/{AccountId}/transactions` with `limit=5` (`hsbc-obie-ais-v4.0:transactions`) in parallel for the selected account. Persists `selectedAccountId` in DataStore so the selection survives app restarts. Derives `InterimAvailable` balance and available balance from `OBCashBalance3` list. Derives spending snapshot from cached PFM Room data — no extra API call. Transitions to empty state when no accounts are authorised or no active consent exists.
