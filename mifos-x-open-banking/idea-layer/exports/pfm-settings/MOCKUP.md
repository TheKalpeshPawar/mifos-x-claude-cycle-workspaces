**Layout notes:**
- Background #F9FAEF; 20dp horizontal padding on label, help and option rows.
- "BASE CURRENCY" section label: Outfit/label_medium, #5C6057, uppercase, 8dp top padding.
- Help text: Outfit/body_small, #5C6057, 8dp bottom padding.
- Each currency row: M3 list item with a leading radio_button; selected row uses #4C662B; tap persists immediately (`select_base_currency`) and shows a snackbar.
- Options are data-driven — one row per distinct currency across the user's personal accounts (EUR/GBP demo set).
- Touch target ≥ 48dp per row.
