## GET /obp/v6.0.0/my/personal-data-fields

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** User
**Trigger:** `loadBaseCurrency()` — on screen entry

Reads the persisted base currency. The store is append-only — the newest row for `pfm_base_currency` wins. When no row exists, the app seeds from the default account's currency.

### Response Fields

| Field                | Type                     | Description                                       |
|----------------------|--------------------------|---------------------------------------------------|
| personal_data_fields | List<PersonalDataField>  | All personal-data-field rows                      |
| name                 | String                   | Field name — filter for `pfm_base_currency`       |
| value                | String                   | Field value (e.g. "EUR")                          |

### Error Codes

| Code | OBP Message        | UI Handling                          |
|------|--------------------|--------------------------------------|
| 401  | USER_NOT_LOGGED_IN | Navigate to login; session expired   |
| —    | network / timeout  | error state: "Could not load settings" + retry |

## POST /obp/v6.0.0/my/personal-data-fields

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** User
**Trigger:** `selectBaseCurrency(code)` — when the user taps a currency radio

Persists the chosen base currency by appending a new row (reads keep the newest).

### Request Body

```json
{
  "name": "pfm_base_currency",
  "value": "EUR"
}
```

### Request Fields

| Field | Type   | Required | Example             | Description                  |
|-------|--------|----------|---------------------|------------------------------|
| name  | String | Yes      | "pfm_base_currency" | Personal-data-field key      |
| value | String | Yes      | "EUR"               | Chosen ISO 4217 currency code|

### Response Fields

| Field | Type   | Description           |
|-------|--------|-----------------------|
| name  | String | Echoed field name     |
| value | String | Echoed stored value   |

### Error Codes

| Code | OBP Message        | UI Error Displayed                              |
|------|--------------------|-------------------------------------------------|
| 400  | INVALID_FIELD_NAME | "Couldn't save your base currency. Try again."  |
| 401  | USER_NOT_LOGGED_IN | Navigate to login; session expired              |

On success the UI shows the snackbar "Base currency set to GBP." (text reflects the chosen code).

## GET /obp/v5.1.0/banks/{bank_id}/fx/{from}/{to}

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** FX
**Trigger:** consumed by the PFM dashboard after the base currency changes — re-denominates personal spending into the selected currency.

### Path Parameters

| Name    | Type   | Required | Demo Value     | Description                |
|---------|--------|----------|----------------|----------------------------|
| bank_id | String | Yes      | mifos.uk.gb.01 | OBP bank identifier        |
| from    | String | Yes      | GBP            | Source currency code       |
| to      | String | Yes      | EUR            | Target (base) currency code|

### Response Fields

| Field                    | Type   | Description                                      |
|--------------------------|--------|--------------------------------------------------|
| conversion_value         | Double | Rate from → to (verified live: GBP→EUR 1.16278)  |
| inverse_conversion_value | Double | Rate to → from                                   |
| effective_date           | String | Rate effective date                              |

### Error Codes

| Code | OBP Message       | UI Handling                                  |
|------|-------------------|----------------------------------------------|
| 404  | FX_RATE_NOT_FOUND | Dashboard falls back to per-currency subtotals|
