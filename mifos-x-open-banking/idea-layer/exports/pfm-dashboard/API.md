## GET /obp/v6.0.0/my/personal-data-fields

**Tag:** User
**Purpose:** Read all personal data fields for the authenticated user. PFM budget entries are stored by convention with the prefix `pfm_budget_<categoryId>` (e.g. `pfm_budget_groceries`, `pfm_budget_transport`).

### Response Fields

| Field | Type | Description |
|---|---|---|
| personal_data_fields | List\<PersonalDataField\> | Array of all personal data field objects |
| name | String | Field key (e.g. "pfm_budget_groceries") |
| value | String | Field value as string (e.g. "400") — parsed as numeric by client |

### Error Codes

| Code | Meaning |
|---|---|
| 401 | USER_NOT_LOGGED_IN — DirectLogin token missing or expired |
| 403 | INSUFFICIENT_AUTHORISATION — token lacks personal data scope |

## POST /obp/v6.0.0/my/personal-data-fields

**Tag:** User
**Purpose:** Create a new personal data field or update an existing one. Used when the user sets or edits a budget for a category.

### Request Body

| Field | Type | Required | Example |
|---|---|---|---|
| name | String | Yes | "pfm_budget_groceries" |
| value | String | Yes | "400" |

### Response Fields

| Field | Type | Description |
|---|---|---|
| name | String | The field key that was created/updated |
| value | String | The stored value |

### Error Codes

| Code | Meaning |
|---|---|
| 400 | INVALID_FIELD_NAME — name does not meet naming constraints |
| 401 | USER_NOT_LOGGED_IN — DirectLogin token missing or expired |
