## GET /obp/v6.0.0/my/personal-data-fields

**Auth:** DirectLogin
**Tag:** User
**Trigger:** `loadDashboardData()` on screen open / `RetryLoad` / period change

### Response Fields

| Field                        | Type                     | Description                                      |
|------------------------------|--------------------------|--------------------------------------------------|
| personal_data_fields         | List\<PersonalDataField\>| Array of user's stored personal data fields      |
| personal_data_fields[].name  | String                   | Field key, e.g. `pfm_budget_food_dining`         |
| personal_data_fields[].value | String                   | Stored value (budget as string amount, e.g. "350")|

**Budget naming convention:** `pfm_budget_<categoryId>` where categoryId ∈ `{food_dining, transport, shopping, bills, entertainment}`.

### Error Codes

| Code | Message                  |
|------|--------------------------|
| 401  | USER_NOT_LOGGED_IN       |
| 403  | INSUFFICIENT_AUTHORISATION|

## GET /obp/v6.0.0/my/accounts/{account_id}/transactions

**Auth:** DirectLogin
**Tag:** Transactions
**Trigger:** `loadDashboardData()` on screen open / period change / `RetryLoad`

### Path Parameters

| Name       | Type   | Description                                |
|------------|--------|--------------------------------------------|
| account_id | String | Primary account ID from accounts response  |

### Query Parameters

| Name      | Type   | Example                    | Description                          |
|-----------|--------|----------------------------|--------------------------------------|
| from_date | String | `2026-05-01T00:00:00Z`     | ISO-8601 start of selected period    |
| to_date   | String | `2026-05-31T23:59:59Z`     | ISO-8601 end of selected period      |
| limit     | Int    | `500`                      | Max transactions to fetch for PFM    |

### Response Fields

| Field                              | Type             | Description                                      |
|------------------------------------|------------------|--------------------------------------------------|
| transactions                       | List\<Transaction\> | Array of transactions in date range           |
| transactions[].transaction_id      | String           | Unique transaction ID                            |
| transactions[].this_account        | AccountInfo      | Account reference                                |
| transactions[].details             | TransactionDetails | Transaction metadata                           |
| transactions[].details.description | String           | Merchant / reference (used for merchant grouping)|
| transactions[].details.posted      | String           | ISO-8601 posted timestamp                        |
| transactions[].details.value       | AmountOfMoney    | Contains `currency` (String) and `amount` (String, signed)|

**PFM aggregation performed client-side:**
- `totalSpent` = sum of negative `details.value.amount`
- `totalReceived` = sum of positive `details.value.amount`
- `categoryBreakdown` = grouping by description keywords mapped to 5 categories
- `topMerchants` = top 4 merchants by absolute spend total

**Sample aggregated values (May 2026):**
- Total Spent: £1,029.80 | Total Received: £3,200.00 | Net: +£2,170.20
- Category Bills: £450.00 (43.7%) — Food & Dining: £320.50 (31.1%) — Transport: £125.00 (12.1%) — Shopping: £89.30 (8.7%) — Entertainment: £45.00 (4.4%)

| Code | Message              |
|------|----------------------|
| 400  | INVALID_DATE_FORMAT  |
