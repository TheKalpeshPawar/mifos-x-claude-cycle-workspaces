## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (TokenExpired — session expired, redirect to login)
- 403 -> ConsentRevoked (consent revoked, redirect to consent-list)
- 429 -> RateLimited (retry with exponential back-off)
- 500 -> Server error (retryable)
- IOException -> NetworkError (retryable)
