## Notes

Called once per locally-stored ConsentId. In the HSBC sandbox a PSU can have at most one active consent; the screen shows all locally-known ConsentIds including Expired/Revoked for history. Results are partitioned client-side into active and history sections.

## Error Handling

All endpoints follow standard error mapping:
- 401 → Auth error — dedicated error_auth state with 'Sign in again' CTA (NOT generic retry)
- 404 → NotFound error — consent absent server-side; remove from local store
- 422 → Validation error
- 500 → Server error (retryable via retry_load)
