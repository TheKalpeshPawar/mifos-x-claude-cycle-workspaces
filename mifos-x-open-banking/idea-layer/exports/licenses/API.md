_No backend API dependencies — this screen renders static or locally-sourced content._

All license data is bundled within the application binary as `composeResources/files/licenses.json`. The `LicenseRepository` reads this asset at startup and exposes it as a `List<LibraryLicense>` to `LicensesViewModel`. No network requests are made. Tapping a library row opens the corresponding license URL (`https://www.apache.org/licenses/LICENSE-2.0` for all 8 Apache 2.0 libraries) via the system browser using `ExternalLinkLauncher` — this browser navigation is not an API call.
