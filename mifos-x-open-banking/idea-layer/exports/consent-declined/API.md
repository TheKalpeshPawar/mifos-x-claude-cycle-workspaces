## Endpoints

(none — this screen performs no network calls; navigation/redirect only)

This is a terminal feedback screen. The declined outcome is delivered entirely via navigation arguments from the auth-callback handler — the callback's `error` and `error_description` query params, and the consent `Status` (RJCT or CANC) resolved during the token exchange or a GET on the consent resource. No OBIE call is made from this screen.

When the PSU taps "Try again", navigation to `consent-request` is emitted and that screen re-issues `POST /obie/open-banking/v4.0/aisp/account-access-consents` — the API call originates from `consent-request`, not from `consent-declined`.
