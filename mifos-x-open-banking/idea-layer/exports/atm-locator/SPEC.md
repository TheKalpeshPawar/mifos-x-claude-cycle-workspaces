**Description:** Find nearby HSBC ATMs using the HSBC Open Data public endpoint (unauthenticated — no AIS consent required). ViewModel fetches the full ATM list once on mount, then applies three client-side predicates in composition: text search on Name + PostCode, service flag filters (24h / WheelchairAccess / CashDeposit toggled by filter chips), and distance sorting via GPS expect/actual with postcode-centroid fallback. The resulting `filteredAtms` stream drives the list. Tapping an ATM card fires a `geo:/maps://` deep-link for native map directions. Not part of the OBIE AIS consent surface.

## 4. State Model

**ViewModel:** `AtmLocatorViewModel`

```
sealed AtmLocatorUiState:
  Loading
  Content(filteredAtms: List<AtmDisplayItem>)
  Empty
  Error(message: String)

View state fields:
  allAtms:      List<AtmDisplayItem>   // full API response; never mutated by filters
  filteredAtms: List<AtmDisplayItem>   // derived; updated by any predicate change
  filterState:  AtmFilterState(is24h: Boolean, hasWheelchairAccess: Boolean, hasCashDeposit: Boolean)
  searchQuery:  String

AtmDisplayItem:
  Name, PostalAddress, PostCode, Latitude (Double), Longitude (Double),
  OpeningHours, HasWheelchairAccess (Boolean), HasCashDeposit (Boolean), Distance (String)

DI:
  AtmRepository             // KtorfitAtmService → GET https://api.hsbc.com/open-banking/v2.2/atms
  GpsDistanceCalculator     // expect/actual — GPS coords + postcode centroid fallback
```

**Actions:**

| Action | Signature | Side Effect |
|---|---|---|
| `atmsLoad` | `suspend fun atmsLoad()` | GET /atms (unauthenticated, 15s timeout); maps OBReadATMResponse1 → List<AtmDisplayItem> |
| `searchAtms` | `fun searchAtms(query: String)` | Client-side only; filters filteredAtms by Name + PostCode; does NOT re-call API |
| `toggleFilter24h` | `fun toggleFilter24h()` | Flips filterState.is24h; re-applies all predicates |
| `toggleFilterWheelchair` | `fun toggleFilterWheelchair()` | Flips filterState.hasWheelchairAccess; re-applies all predicates |
| `toggleFilterDeposit` | `fun toggleFilterDeposit()` | Flips filterState.hasCashDeposit; re-applies all predicates |
| `openAtmDirections` | `fun openAtmDirections(atm: AtmDisplayItem)` | Fires `geo:/maps://` intent (expect/actual); no ViewModel state change |
| `retryLoad` | `suspend fun retryLoad()` | Resets filterState to defaults then delegates to atmsLoad() |

## 5. Navigation

**No in-app navigation targets.** Card tap fires OS-level `geo:/maps://` deep-link (KMP expect/actual) — platform native Maps app handles directions.

**Incoming route params:** none required. `accountId` may be passed from account-detail but is not currently used by this screen (future: pre-filter by branch area from sort-code).

**Back navigation:** Top App Bar leading back button → pops to caller (typically `account-detail` or bottom-nav root).
