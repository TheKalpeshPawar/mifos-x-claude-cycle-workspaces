**Description:** Calls HSBC Open Data GET /atms (unauthenticated, Ktorfit, 15s timeout). ViewModel stores full ATM list in allAtms, applies three client-side predicates in composition: text search on Name + PostCode, service flags (is24h / hasWheelchairAccess / hasCashDeposit toggled by filter chips), and distance sort via GPS expect/actual with postcode-centroid fallback. The resulting filteredAtms stream drives the list. Card tap emits geo:/maps:// deep-link for directions. No OBIE consent scope or FAPI auth flow involved.

### Sealed Class — AtmLocatorUiState

| Member | Notes |
|---|---|

| Error Class | Trigger | User Message | Recovery |
|---|---|---|---|
| `NetworkError` | IOException / SocketTimeoutException — HSBC Open Data unreachable | Could not reach HSBC Open Data. Check your connection. | retry_load |
| `HttpServerError` | HTTP 5xx — HSBC Open Data service unavailable | HSBC Open Data service unavailable. Please try again. | retry_load |

| `retryLoad` | `suspend fun retryLoad()` | Resets filterState to default (all-off); delegates to atmsLoad | Re-enters Loading → Content/Empty/Error |
