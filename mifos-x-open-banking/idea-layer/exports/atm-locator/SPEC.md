## Overview

The ATM & Branch Locator screen enables consumers to find nearby Mifos ATMs and branches using GPS or manual address search. A map view displays pin locations while a scrollable list below shows results with distance, opening hours, and withdrawal limits. Filter chips allow narrowing results to ATMs only, branches only, or 24/7 locations. Each result card provides a direct "Get Directions" link that opens the device's native maps application. A location permission banner is shown when the user has not yet granted location access.

## States

| ID | Trigger | Description |
|---|---|---|
| loading | Screen enters; API calls in flight | Title, search and filter chips visible; map and result cards shown as skeletons |
| content | Location and API data available | Map renders, result count header shows, all result cards visible |
| error | Network or API failure | Title and search input only; map and results hidden; error message shown |
| empty | Search returns no results | Title, search, filter chips; empty message "No ATMs or branches found in this area" |
| location_denied | User has not granted location permission | Location banner + Enable button shown; map hidden |
