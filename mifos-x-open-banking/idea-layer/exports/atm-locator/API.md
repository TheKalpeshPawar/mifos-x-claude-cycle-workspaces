## Overview

ATM Locator makes **1 network call** on screen mount. The endpoint is a public Open Data product-level API — no OBIE consent, no FAPI 1.0 bearer token, and no AIS permission scope required.

| Call | Method | Path | Auth | Media Type |
|---|---|---|---|---|
| ATM list | GET | `/atms` | None | `application/prs.openbanking.opendata.v2.2+json` |

`network_policy: cellular_allowed`. Response is cached in ViewModel memory (allAtms) for 60 minutes using a stale-while-revalidate strategy — ATM locations change rarely and the endpoint is unauthenticated, so disk persistence is not warranted.

## Caching Policy

| Property | Value |
|---|---|
| Strategy | stale-while-revalidate |
| TTL | 60 minutes |
| Storage | ViewModel memory only (`allAtms` field); cleared on screen dismissal |
| Rationale | ATM locations change rarely (branch relocations are infrequent). A 60-minute in-memory cache avoids redundant Open Data calls on cellular and matches the unauthenticated, public nature of the endpoint |

---

## Notes

- No `Authorization` header. No OAuth token. No signed request object.
- The `Accept: application/prs.openbanking.opendata.v2.2+json` header is **required** — the endpoint returns HTTP 406 without it.
- This endpoint is entirely separate from the consent-gated OBIE AIS surface. It does not count against OBIE rate limits (500 calls/5 min PSU limit).
- `ATMServices`, `Accessibility`, and `SupportedCurrencies` are string-enum arrays per the OBIE Open Data API Specification v2.4.
