## Overview

ATM Locator makes a **single unauthenticated** call to the HSBC Open Data product-public endpoint. No AIS consent, no Bearer token, no FAPI signed request object.

| Call | Method | Full URL | Auth |
|---|---|---|---|
| Fetch all HSBC ATMs | GET | `https://api.hsbc.com/open-banking/v2.2/atms` | None |

> **Note:** This endpoint is separate from the consent-gated OBIE AIS surface (`/open-banking/v4.0/aisp/*`). It is publicly accessible and not subject to FAPI 1.0 Advanced constraints.

## Endpoint — GET /atms

```
GET https://api.hsbc.com/open-banking/v2.2/atms

Auth:     None
Accept:   application/prs.openbanking.opendata.v2.2+json   ← REQUIRED
          (endpoint returns HTTP 406 if this header is absent)
Timeout:  15 seconds (Ktorfit configuration)
```

### Response Field Mapping → AtmDisplayItem DTO

| AtmDisplayItem field | Source path in response | Transformation |
|---|---|---|
| `Name` | `Brand[0].ATM[*].Identification` | Used as display name (e.g. "Camden Town" if provider enriches it) |
| `PostalAddress` | `ATM.Location.PostalAddress.AddressLine` + `PostCode` | `AddressLine.joinToString(", ") + ", " + PostCode` |
| `PostCode` | `ATM.Location.PostalAddress.PostCode` | Raw string; used for postcode centroid distance fallback |
| `HasWheelchairAccess` | `ATM.Accessibility` | `contains("WheelchairAccess")` |
| `HasCashDeposit` | `ATM.ATMServices` | `contains("CashDeposit")` |
| `Latitude` | `ATM.Location.PostalAddress.GeoLocation.GeographicCoordinates.Latitude` | `.toDouble()` |
| `Longitude` | `ATM.Location.PostalAddress.GeoLocation.GeographicCoordinates.Longitude` | `.toDouble()` |
| `OpeningHours` | derived from `ATMServices` | "24 hours" if CashWithdrawal present 24/7, else formatted hours string |
| `Distance` | computed | `GpsDistanceCalculator.computeDistance(Latitude, Longitude)` or postcode-centroid fallback |

## Error Matrix

| Condition | Error type | UI State | User Message | Recovery |
|---|---|---|---|---|
| Device offline / Ktorfit read timeout (> 15s) | `IOException` / `SocketTimeoutException` | `AtmLocatorUiState.Error` | "Could not reach HSBC Open Data. Check your connection." | `retry_load` (resets filterState) |
| HTTP 500–599 from HSBC Open Data | `HttpException` (5xx) | `AtmLocatorUiState.Error` | "HSBC Open Data service unavailable. Please try again." | `retry_load` |
| HTTP 400–499 (unexpected; no auth involved) | `HttpException` (4xx) | `AtmLocatorUiState.Error` | "Unexpected error from HSBC Open Data." | `retry_load` |
| `data[0].atm` returns empty list or null | `EmptyResult` | `AtmLocatorUiState.Empty` | — (empty_state UI; no message needed) | Adjust filters |

> **Unauthenticated endpoint:** HTTP 401 and 403 are not expected responses and are grouped under 4xx handling above.

## Client-Side Filtering (not API calls)

The following operations are **ViewModel-only** — they do NOT trigger additional API calls:

| Action | Behaviour |
|---|---|
| `searchAtms(query)` | Filters `allAtms` by `Name` + `PostCode` substring match (case-insensitive) |
| `toggleFilter24h()` | Applies `is24h` predicate to `allAtms` |
| `toggleFilterWheelchair()` | Applies `hasWheelchairAccess` predicate to `allAtms` |
| `toggleFilterDeposit()` | Applies `hasCashDeposit` predicate to `allAtms` |

`allAtms` is fetched once on mount. `filteredAtms` is a derived view updated on every predicate change. No re-fetch occurs unless `retryLoad` is explicitly triggered.

## SLA Notes

- Public Open Data endpoint — no formal SLA guarantee from HSBC.
- Use 15-second Ktorfit timeout to prevent indefinite hangs.
- No exponential back-off applied; retry is manual (user-initiated).
- No disk caching; data refetches on every fresh navigation to this screen.
