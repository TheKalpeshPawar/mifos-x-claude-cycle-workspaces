## Error Handling

All endpoints follow standard error mapping:
- 401 -> Auth error (Session expired — redirect to signin)
- 403 -> Permission error (ReadProducts not in consent — show error with message)
- 404 -> Not found (no product record — show error with message, retryable)
- 500 -> Server error (retryable)
- 200 with empty Data[] or null PCA/BCA -> Empty state (informational, NOT error)
