# API Reference — Transaction History
**Feature:** transactions | **Base URL:** https://apisandbox.openbankproject.com

---

## GET /obp/v5.1.0/my/banks/{bankId}/accounts/{accountId}/transactions

Retrieves a paginated list of transactions for a specific account. Supports date range filtering, transaction type filtering, and sort direction.

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** Transactions

### Path Parameters

| Name | Type | Required | Example |
|---|---|---|---|
| bankId | String | Yes | gh.29.uk |
| accountId | String | Yes | acc_checking_primary |

### Query Parameters

| Name | Type | Required | Default / Example | Notes |
|---|---|---|---|---|
| limit | Integer | No | 20 | Page size |
| offset | Integer | No | 0 | Zero-based page offset |
| from_date | String (ISO 8601) | No | 2026-04-25T00:00:00.000Z | Start of date range |
| to_date | String (ISO 8601) | No | 2026-05-25T23:59:59.999Z | End of date range |
| type | String | No | DEBIT / CREDIT / SEPA_CREDIT_TRANSFERS / UK_FASTER_PAYMENTS_SEND | Filter by transaction type; omit for ALL |
| sort_direction | String | No | DESC | ASC or DESC by posted date |

### Response Fields

| Field | Type | Description |
|---|---|---|
| id | String | Unique transaction identifier |
| this_account | Object | Owning account reference |
| other_account.holder | Object | Counterparty holder data |
| other_account.metadata | Object | Counterparty metadata (merchant info) |
| details.type | String | Transaction type code |
| details.description | String | Human-readable description / merchant name |
| details.posted | String | ISO 8601 posting timestamp |
| details.completed | String | ISO 8601 completion timestamp |
| details.new_balance.currency | String | Account currency after transaction |
| details.new_balance.amount | String | Account balance after transaction |
| details.value.currency | String | Transaction currency |
| details.value.amount | String | Signed transaction amount (negative = debit) |
| metadata | Object | OBP metadata block (narrative, comments, tags) |

### Error Codes

| HTTP Code | Message | Resolution |
|---|---|---|
| 400 | Invalid date range or filter parameters | Validate ISO 8601 date format and allowed type values |
| 401 | Unauthorized | Re-authenticate via POST /my/logins/direct |
| 404 | Account not found | Verify accountId against authenticated user's accounts |
| 500 | OBP server error | Retry with exponential backoff |
