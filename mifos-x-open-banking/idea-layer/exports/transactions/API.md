## GET /accounts/{AccountId}/transactions

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| AccountId | string | yes | OBIE AccountId; passed as route param from account-detail |

### Query Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| fromBookingDateTime | string (ISO-8601 date-time) | no | Lower bound for BookingDateTime filter (e.g. 2026-06-01T00:00:00Z). Set when PSU confirms a date range via the date-range chip. |
| toBookingDateTime | string (ISO-8601 date-time) | no | Upper bound for BookingDateTime filter (e.g. 2026-06-28T23:59:59Z). Set when PSU confirms a date range via the date-range chip. |

### Response: OBReadTransaction6 (HTTP 200)

**Data path**: `OBReadTransaction6.Data.Transaction[]` (OBTransaction6 items)

| Field | Type | Notes |
|-------|------|-------|
| TransactionId | string | Used as key when navigating to transaction-detail |
| AccountId | string | Passed as route param to transaction-detail |
| CreditDebitIndicator | string | Credit (primary color) / Debit (error color); drives client-side filter |
| Status | string | Booked / Pending; Pending → warning badge in transaction_row |
| BookingDateTime | string (ISO-8601 UTC) | Grouped by LocalDate via kotlinx-datetime |
| ValueDateTime | string (ISO-8601 UTC) | May differ from BookingDateTime for pending transactions |
| Amount.Amount | string (decimal) | Transaction amount |
| Amount.Currency | string (ISO 4217) | Currency code (e.g. GBP) |
| MerchantDetails.MerchantName | string? | Displayed in transaction_row; may be null for direct credits |
| MerchantDetails.MerchantCategoryCode | string? | ISO 18245 MCC; input to client-side Category lookup |
| TransactionInformation | string | Free-text narrative; also used for search and clipboard copy |
| ProprietaryBankTransactionCode.Code | string | HSBC proprietary code; input to client-side Category lookup |
| ProprietaryBankTransactionCode.Issuer | string | Code issuer |

**Pagination**: OBIE Links.Next cursor-based pagination.

| Pagination field | Path | Notes |
|-----------------|------|-------|
| Links.Self | OBReadTransaction6.Links.Self | Absolute URL for current page |
| Links.Next | OBReadTransaction6.Links.Next | Absolute URL for next page; null when no further pages exist. Stored as `next_link` state. Page size is HSBC-controlled (~100 transactions/page). |
| Links.Last | OBReadTransaction6.Links.Last | Absolute URL for final page; nullable |
| Meta.TotalPages | OBReadTransaction6.Meta.TotalPages | Total number of pages; nullable |

**Client-side processing applied after fetch**:

| Operation | Description |
|-----------|-------------|
| Date grouping | Group by BookingDateTime LocalDate via kotlinx-datetime; format "EEE d MMM yyyy" for date_group_header |
| CreditDebitIndicator filter | Applied against accumulated in-memory list; no re-fetch |
| Text search | Case-insensitive substring match on TransactionInformation + MerchantDetails.MerchantName; no re-fetch |
| Period totals | Sum Credit amounts (money-in) + sum Debit amounts (money-out) from currently-filtered set |
| Category derivation | TransactionCategoryMapper.kt MCC lookup from ProprietaryBankTransactionCode.Code or MerchantCategoryCode; pure-Kotlin common code; not returned by API |

### Error Mapping

| HTTP | Error Class | Recoverable | UI State |
|------|-------------|-------------|----------|
| 401 | TokenExpiredError | true | `Error("Session expired. Please log in again.")` + Retry button |
| 403 | ConsentWithdrawnError | false | `Error("Access to transactions has been withdrawn.")` — no Retry |
| 429 | RateLimitError | true | `Error("Too many requests. Please wait a moment and retry.")` + Retry |
| Network (IOException) | NetworkError | true | `Error("No network connection. Please check your connection and retry.")` + Retry |
| 200 + empty Data.Transaction[] | — | — | `Empty` state |

### Pagination Behaviour

| Trigger | Behaviour |
|---------|-----------|
| Screen mount / `retryLoad` | Fetch first page (no fromBookingDateTime / toBookingDateTime unless date range set); reset nextLink=null, hasNextPage=false, isPaginating=false |
| Load more button tapped | GET nextLink URL via ktorfit; append rows to in-memory list; update nextLink from response; update hasNextPage |
| Date range confirmed | Reset pagination cursor (nextLink=null); re-fetch page 1 with fromBookingDateTime + toBookingDateTime query params |
| Credit/debit filter chip | Client-side only; no network request |
| Search field | Client-side only; no network request |
