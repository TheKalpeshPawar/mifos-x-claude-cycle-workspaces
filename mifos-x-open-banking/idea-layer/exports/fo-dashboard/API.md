## GET /obp/v5.1.0/banks/{bankId}/customers

Fetches the list of customers assigned to the authenticated field officer's bank. Used to populate `activeCustomerCount` and action alerts on the dashboard.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | The OBP bank identifier (e.g. `mifos-nairobi`) |

### Response Fields

| Field | Type | Description |
|---|---|---|
| customers | List\<Customer\> | Array of customer objects |
| customer_id | String | Unique customer identifier |
| legal_name | String | Full legal name |
| kyc_status | String | Current KYC status (e.g. `verified`, `pending`) |
| customer_number | String | Bank-assigned customer number |
| mobile_phone_number | String | Primary contact phone |
| date_of_birth | String | ISO date string |

### Error Codes

| Code | Meaning |
|---|---|
| 401 | Unauthorized — missing or invalid DirectLogin token |
| 404 | Bank not found |
| 500 | Internal server error |

## GET /obp/v5.1.0/banks/{bankId}/account-applications

Fetches account applications for the bank. Used to populate `pendingApplicationCount` and the pending-application action alerts.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | The OBP bank identifier |

### Response Fields

| Field | Type | Description |
|---|---|---|
| account_applications | List\<AccountApplication\> | Array of application objects |
| account_application_id | String | Unique application identifier |
| product_code | String | Product being applied for |
| proposed_balance | Amount | Initial proposed balance (`{currency, amount}`) |
| status | String | Application status (e.g. `pending`, `approved`) |
| date_of_application | String | ISO datetime of submission |

### Error Codes

| Code | Meaning |
|---|---|
| 401 | Unauthorized — missing or invalid DirectLogin token |
| 404 | Bank not found |
| 500 | Internal server error |
