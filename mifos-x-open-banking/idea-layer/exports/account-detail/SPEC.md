**Description:** Single account detail screen — account metadata (Nickname, Identification, Currency, AccountSubType, Servicer, StatusUpdateDateTime) and all OBCashBalance3 balance types fetched in parallel via ktorfit. Includes an Open Banking trust badge (OBIE CX transparency requirement) and a horizontal scrollable chip row with **9 action chips** navigating to related AIS sub-screens: transactions, statements, standing-orders, direct-debits, scheduled-payments, beneficiaries, atm-locator, **product**, and **party** (product and party chips added 2026-07-14). Typed error handling covers 401/403/404/network with per-error recoverability. Empty state handles zero-balance accounts (e.g. Global Wallet sub-accounts).

## 4. State Model

**ViewModel:** `AccountDetailViewModel`

```
State fields:
  accountId: String
  uiState: AccountDetailUiState

sealed AccountDetailUiState:
  Loading
  Content(account: OBAccount6, balances: List<OBCashBalance3>)
  Empty(account: OBAccount6)               // balances[] is empty
  Error(code: Int?, message: String, recoverable: Boolean)

Error types + recoverability:
  TokenExpiredError     HTTP 401  recoverable=true   recovery=retry_load
  ConsentWithdrawnError HTTP 403  recoverable=false  recovery=navigate_back
  AccountNotFoundError  HTTP 404  recoverable=false  recovery=navigate_back
  NetworkError          null      recoverable=true   recovery=retry_load
  UnexpectedError       null      recoverable=true   recovery=retry_load

DI:
  AccountDetailRepository  // ktorfit GET /accounts + GET /accounts/{id}/balances
  NavigationController     // KMP nav abstraction for push/pop
```

**Actions:**

| `navigateBack` | `fun navigateBack()` | Pop nav stack → accounts |
