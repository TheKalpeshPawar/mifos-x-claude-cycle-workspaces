| Archetype | `detail_screen` |
| Cluster | `account` |
| Acceptance refs | FR-003, FR-004 |
| Quality score | 95 |
| Implementation ready | Yes (2026-06-29) |

**Description:** Fetches account metadata and balances in parallel via ktorfit (GET /accounts/{id} + GET /accounts/{id}/balances); produces AccountDetailUiState (Loading/Content/Empty/Error) with typed error handling (401/403/404/network). Chip row navigates to transactions, statements, standing-orders, direct-debits, scheduled-payments, beneficiaries, atm-locator, product, and party, each scoped by accountId.

### Sealed Class — AccountDetailUiState

| Member | Type parameters | Notes |
|---|---|---|
| `Loading` | — | Spinner shown; both API calls in flight |
| `Content` | account: OBAccount6, balances: List\<OBCashBalance3\> | Non-empty balances array |
| `Empty` | account: OBAccount6 | balances array is empty (e.g. Global Wallet sub-account) |
| `Error` | code: Int?, message: String, recoverable: Boolean | Typed by HTTP status |

### Error Types

| Error Class | HTTP Status | Recoverable | User Message | Recovery Action |
|---|---|---|---|---|
| `TokenExpiredError` | 401 | true | Session expired. Please log in again. | retry_load |
| `ConsentWithdrawnError` | 403 | false | Access to this account has been withdrawn. | navigate_back |
| `AccountNotFoundError` | 404 | false | Account not found in your authorised account set. | navigate_back |
| `NetworkError` | network/timeout | true | No network connection. Please check your connection and retry. | retry_load |
| `UnexpectedError` | default | true | Something went wrong. Please try again. | retry_load |
