## Error Handling

All endpoints follow standard error mapping:
- 401 → TokenExpiredError (recoverable=true — show Retry; re-enter loading state)
- 403 → ConsentWithdrawnError (recoverable=false — show Back only; no Retry)
- 404 → AccountNotFoundError (recoverable=false — show Back only)
- network → NetworkError (recoverable=true — show Retry)
- default → UnexpectedError (recoverable=true — show Retry)

**Both API calls run in parallel coroutines.** If either fails, the error type is determined by the first failing call's HTTP status code.
