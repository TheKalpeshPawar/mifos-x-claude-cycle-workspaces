## Purpose

Fetches `OBReadConsentResponse1` from `hsbc-obie-ais-v4.0:account-access-consents/{ConsentId}` via Ktorfit, maps `Data.Permissions[]` to human-readable `PermissionDetail` labels via PermissionsMapper, and renders a color-coded OBIE Status chip (primary=Authorised, warning=Expired/AwaitingAuthorisation, error=Revoked/Rejected). The ViewModel computes `expiryWarningDays` from `ExpirationDateTime`: when ≤7 days, surfaces an expiry warning banner. Revoke is a guarded two-step: `ConfirmRevoke` transitions to `RevokeConfirm` (dialog), `ExecuteRevoke` dispatches DELETE `/account-access-consents/{ConsentId}`; 204 triggers local PSU token and ConsentId clearance then navigates to consent-list; 404 is idempotently treated as already-revoked (same cleanup path, no error shown).
