## GET /obp/v5.1.0/my/consents

**Auth:** DirectLogin
**Tag:** Consent
**Trigger:** `loadConsents()` on screen open / `RetryLoad` event

### Response Fields

| Field             | Type                    | Description                                          |
|-------------------|-------------------------|------------------------------------------------------|
| consents          | List\<Consent\>         | All PSD2 consents granted by the authenticated user  |
| consent_id        | String                  | Unique consent identifier (used for revoke call)     |
| status            | String                  | `INITIATED` \| `ACCEPTED` \| `REVOKED` \| `EXPIRED` |
| created_at        | String                  | ISO-8601 UTC consent creation timestamp              |
| valid_until       | String                  | ISO-8601 UTC consent expiry timestamp                |
| consumer_id       | String                  | ID of the third-party app consumer                   |
| redirects         | List\<ConsentRedirect\> | OAuth redirect URIs registered for this consent      |
| json_web_token    | String                  | JWT encoding the consent scopes and metadata         |

### ConsentItem (mapped from OBP Consent)

| Field      | Type     | Source                    | Description                                    |
|------------|----------|---------------------------|------------------------------------------------|
| id         | String   | consent_id                | Used as key for revoke call                    |
| appName    | String   | consumer metadata         | Display name e.g. "MoneyManager Pro"           |
| grantedAt  | String   | created_at                | Formatted as "1 Mar 2026"                      |
| expiresAt  | String   | valid_until               | Formatted as "1 Mar 2027"                      |
| status     | String   | status                    | ACTIVE (ACCEPTED) or EXPIRED                   |
| scopes     | List\<String\> | jwt payload scope | e.g. ["Read Accounts", "View Transactions"]   |

### Error Codes

| Code | OBP Error Key              | UI Behaviour                                    |
|------|----------------------------|-------------------------------------------------|
| 401  | USER_NOT_LOGGED_IN         | Navigate to login                               |
| 403  | INSUFFICIENT_AUTHORISATION | Show error state with message                   |
| 500  | INTERNAL_SERVER_ERROR      | Show error state + retry button                 |

## DELETE /obp/v5.1.0/my/consents/{consentId}

**Auth:** DirectLogin
**Tag:** Consent
**Trigger:** `RevokeConsentConfirmed(consentId)` event — after user taps "Revoke" in the confirmation dialog

### Path Parameters

| Name      | Type   | Description                                        |
|-----------|--------|----------------------------------------------------|
| consentId | String | ID of the consent to revoke (from ConsentItem.id)  |

### Response Fields

| Field      | Type   | Description                                  |
|------------|--------|----------------------------------------------|
| consent_id | String | ID of the revoked consent (for local removal) |
| status     | String | `REVOKED` — confirms successful revocation   |

### Error Codes

| Code | OBP Error Key              | UI Behaviour                                                        |
|------|----------------------------|---------------------------------------------------------------------|
| 401  | USER_NOT_LOGGED_IN         | Navigate to login                                                   |
| 404  | CONSENT_NOT_FOUND          | Show snackbar "This app was already disconnected"; refresh list     |
| 500  | INTERNAL_SERVER_ERROR      | Show snackbar "Could not revoke access. Please try again."; keep dialog |
