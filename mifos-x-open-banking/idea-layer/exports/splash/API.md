No direct API calls — data passed via navigation parameters.

The Splash screen performs session resolution entirely via local `SessionManager` (reads the persisted DirectLogin token or OAuth access_token from `CredentialStore`). No network requests are issued on this screen.

If the stored token is found and non-expired, navigation fires immediately to `home` or `fo-dashboard` without any HTTP call. If the token is absent or expired, the app navigates to `login`, where the actual authentication API calls occur.

For the authentication endpoints used after this screen, see `idea-layer/exports/login/API.md`.
