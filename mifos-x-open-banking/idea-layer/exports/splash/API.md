_No backend API dependencies — this screen renders static or locally-sourced content._

The Splash screen performs session resolution entirely via local `SessionManager` (reads the persisted DirectLogin token from `CredentialStore`). No HTTP requests are issued on this screen.

**Session resolution logic:**

| Scenario                        | Resolution                               | Navigate to    | Delay   |
|---------------------------------|------------------------------------------|----------------|---------|
| No stored token                 | `hasValidToken = false`                  | login          | 2 000 ms|
| Valid token + role CONSUMER     | `hasValidToken = true`, role resolved    | home           | 0 ms    |
| Valid token + role FIELD_OFFICER| `hasValidToken = true`, role resolved    | fo-dashboard   | 0 ms    |
| Expired token (refresh needed)  | `ObpAuthRepository.refreshToken()` called| login on fail  | —       |

For authentication endpoints called on the login screen, see `idea-layer/exports/login/API.md`.
