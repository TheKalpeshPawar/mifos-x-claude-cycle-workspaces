## PUT /obp/v5.0.0/users/{userId}/password

**Auth:** DirectLogin
**Tag:** Users
**Trigger:** `onSubmitClicked()` — dispatched from `ChangePasswordViewModel` after client-side validation passes

### Path Parameters

| Name   | Type   | Description                                 |
|--------|--------|---------------------------------------------|
| userId | String | Authenticated user's OBP user ID (from `SessionManager`) |

### Request Body

| Field            | Type   | Required | Description                          |
|------------------|--------|----------|--------------------------------------|
| current_password | String | Yes      | User's existing account password     |
| new_password     | String | Yes      | Desired new password (min 8 chars)   |

### Response Fields

| Field   | Type    | Description                            |
|---------|---------|----------------------------------------|
| success | Boolean | `true` on successful password change   |
| message | String  | Human-readable confirmation message    |

### Error Codes

| Code | OBP Error Key            | UI Message                                                                 |
|------|--------------------------|----------------------------------------------------------------------------|
| 400  | INCORRECT_CURRENT_PASSWORD | "Password change failed. Please check your current password and try again." |
| 401  | USER_NOT_LOGGED_IN       | "Session expired. Please log in again."                                    |
| 403  | INSUFFICIENT_AUTHORISATION | "You are not authorised to change this password."                        |
| 500  | INTERNAL_SERVER_ERROR    | "Could not connect. Please check your connection and try again."           |
