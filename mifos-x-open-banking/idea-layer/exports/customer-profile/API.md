## GET /obp/v5.1.0/banks/{bankId}/customers/{customerId}

Loads the full customer record for display across all profile sections.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |
| customerId | String | OBP customer identifier |

### Response Fields (Profile-relevant subset)

| Field | Type | Description |
|---|---|---|
| customer_id | String | Unique customer identifier |
| legal_name | String | Full legal name (displayed as "John Kamau Mwangi") |
| date_of_birth | String | ISO date — rendered with age calculation |
| national_id_number | String | National ID (e.g. KE12345678) |
| tax_pin | String | KRA Tax PIN (e.g. A001234567M) |
| mobile_phone_number | String | Primary phone — rendered as tappable call link |
| email | String | Email address — rendered as tappable mailto link |
| address | Address | Nested address object (street, county, postcode) |
| employment_details | EmploymentDetails | Nested employment object (employer, income, type) |

### Error Codes

| Code | Meaning |
|---|---|
| 400 | BAD_REQUEST |
| 401 | UNAUTHORIZED |
| 404 | CUSTOMER_NOT_FOUND |

## PUT /obp/v5.1.0/banks/{bankId}/customers/{customerId}

Submits updated customer information when the officer taps "Edit Information" and saves changes.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |
| customerId | String | OBP customer identifier |

### Request Body

Send only fields being updated. All fields optional in PATCH semantics.

| Field | Type | Description |
|---|---|---|
| legal_name | String | Updated full legal name |
| mobile_phone_number | String | Updated phone number |
| email | String | Updated email address |
| address | Address | Updated address object |
| employment_details | EmploymentDetails | Updated employer, income, employment type |

### Response Fields

| Field | Type | Description |
|---|---|---|
| customer_id | String | Confirmed customer identifier |
| legal_name | String | Confirmed updated name |
| last_ok_date | String | Timestamp of successful update |

### Error Codes

| Code | Meaning |
|---|---|
| 400 | VALIDATION_FAILED — one or more field validation errors |
| 401 | UNAUTHORIZED |
| 404 | CUSTOMER_NOT_FOUND |
