## GET /obp/v5.0.0/banks/{bankId}/products

**Auth:** DirectLogin
**Tag:** Product
**Trigger:** `loadProducts()` on screen open / `RetryLoad` event / category filter change

### Path Parameters

| Name   | Type   | Value    | Description            |
|--------|--------|----------|------------------------|
| bankId | String | gh.29.uk | OBP sandbox bank ID    |

### Response Fields

| Field                        | Type                | Description                                                       |
|------------------------------|---------------------|-------------------------------------------------------------------|
| products                     | List\<Product\>     | Array of available banking products                               |
| products[].code              | String              | Unique product code (e.g. `INSTANT-SAVINGS-001`)                  |
| products[].name              | String              | Display name (e.g. "Instant Access Savings")                      |
| products[].category          | String              | Category enum: `SAVINGS`, `LOANS`, `CARDS`, `MORTGAGES`, `CURRENT`|
| products[].family            | String              | Product family grouping                                           |
| products[].super_family      | String              | Super-family grouping                                             |
| products[].more_info_url     | String              | URL for full product detail page                                  |
| products[].details           | ProductDetails      | Rate, terms, and feature attributes (structure varies by category)|
| products[].meta              | ProductMeta         | Metadata including license info                                   |

**Client-side mapping for display:**

| Product Name             | code prefix   | rate display        | features                                   |
|--------------------------|---------------|---------------------|--------------------------------------------|
| Instant Access Savings   | savings       | "4.5% AER"          | 4.5% AER, Instant access, No minimum      |
| Fixed Rate Bond 1yr      | savings       | "5.1% AER"          | 5.1% AER, 12-month term, FSCS protected   |
| Personal Loan            | loans         | "From 6.9% APR"     | From 6.9% APR, Up to £25,000, 1–7 yr terms|
| Platinum Credit Card     | cards         | "0% for 20 months"  | 0% 20 months, No annual fee, Contactless  |

### Error Codes

| Code | Message              | UI Behaviour                                           |
|------|----------------------|--------------------------------------------------------|
| 400  | INVALID_BANK_ID      | Error state with Retry                                 |
| 401  | USER_NOT_LOGGED_IN   | Navigate to login                                      |
| 404  | BANK_NOT_FOUND       | Error state with Retry                                 |
| 503  | SERVICE_UNAVAILABLE  | Error state: "Check your connection and try again."   |
