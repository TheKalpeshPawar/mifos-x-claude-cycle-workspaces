## GET /obp/v3.1.0/banks/{bankId}/products

**Tag:** Product
**Purpose:** Fetch the full product catalogue for a bank, used to populate the product cards and apply category filters client-side.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |

### Response Fields

| Field | Type | Description |
|---|---|---|
| products | List\<Product\> | Array of product objects |
| code | String | Unique product code used as key for expand/apply actions |
| name | String | Human-readable product name (e.g. "Current Plus Account") |
| category | String | Product category for filter tabs (e.g. "CURRENT", "SAVINGS", "LOAN") |
| family | String | Product family grouping |
| super_family | String | Top-level product family |
| more_info_url | String | Deep-link URL for full product detail page |
| details | ProductDetails | Nested object with rate, fee, term, and eligibility data |

### Error Codes

| Code | Meaning |
|---|---|
| 400 | INVALID_BANK_ID — provided bankId is not valid |
| 401 | USER_NOT_LOGGED_IN — DirectLogin token missing or expired |
| 404 | BANK_NOT_FOUND — no bank matches the provided bankId |
