## Purpose

Receives the FAPI-1.0-Advanced authorisation redirect from HSBC. Validates the state parameter and the hybrid-flow id_token nonce against locally stored values; on mismatch shows security_error immediately without attempting token exchange. If route params carry error=access_denied, shows the access-denied state. On a valid code, calls HSBC `/oauth2/token` (authorization_code grant, private_key_jwt client auth) via Ktorfit; stores PSU access+refresh tokens in EncryptedSharedPreferences. Then polls GET `/account-access-consents/{ConsentId}` with a client_credentials token until Status is Authorised (auto-navigate to accounts), AwaitingAuthorisation (empty state with manual re-poll), or Rejected / HTTP 400-401 (error state, retry path to login).
