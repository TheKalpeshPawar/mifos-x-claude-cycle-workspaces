## POST /oauth2/token

FAPI-1.0-Advanced authorization_code token exchange. Called immediately after the FAPI state and id_token nonce are validated locally.

### Request Body (application/x-www-form-urlencoded)

| Field | Type | Value | Notes |
|-------|------|-------|-------|
| grant_type | string | `authorization_code` | Fixed value |
| code | string | `{route_params.code}` | Single-use auth code from HSBC redirect (~10 min TTL) |
| redirect_uri | string | `{registered_redirect_uri}` | Must exactly match the URI registered with HSBC |
| client_assertion_type | string | `urn:ietf:params:oauth:client-assertion-type:jwt-bearer` | Fixed value per FAPI |
| client_assertion | string | `{private_key_jwt}` | JWT signed with the registered private key |

### Response: OAuthTokenResponse (HTTP 200)

| Field | Type | Notes |
|-------|------|-------|
| access_token | string | PSU bearer token — stored in EncryptedSharedPreferences |
| refresh_token | string | Stored alongside access_token |
| token_type | string | `Bearer` |
| expires_in | int | Seconds until access_token expires |

### Error Codes

| HTTP | Cause | UI Outcome |
|------|-------|------------|
| 400 | Bad/expired code or redirect_uri mismatch | Error state (TokenExchangeFailed, non-retriable) |
| 401 | private_key_jwt assertion invalid or key not registered | Error state (non-retriable) |

## GET /account-access-consents/{ConsentId}

Called after the token exchange to confirm that the OBIE consent Status has advanced to Authorised. Authenticated with a **client_credentials** token — NOT the PSU bearer token.

### Path Parameters

| Param | Type | Notes |
|-------|------|-------|
| ConsentId | string | Stored locally before the FAPI redirect was initiated |

### Response: OBReadConsentResponse1 (HTTP 200)

| Field | Type | Notes |
|-------|------|-------|
| Data.Status | string | `Authorised` \| `AwaitingAuthorisation` \| `Rejected` \| `Consumed` \| `Revoked` |
| Data.Permissions[] | string[] | OBIE permission codes granted by the PSU |
| Data.CreationDateTime | ISO-8601 datetime | When the consent was created |
| Data.ExpirationDateTime | ISO-8601 datetime | 90-day OBIE expiry |

### Status Branching (ViewModel logic)

| Data.Status | ViewModel Outcome |
|-------------|-------------------|
| Authorised | Transition to content state; auto-navigate to accounts after 1.5 s |
| AwaitingAuthorisation | Transition to empty state; manual re-poll via poll_again_button |
| Rejected \| Revoked | Transition to error state (ConsentRejected / ConsentRevoked) |

### Error Codes

| HTTP | Cause | UI Outcome |

| 404 | ConsentId not found (stale or already consumed) | Error state |

## Auth/Consent Notes

- The token-exchange endpoint uses **private_key_jwt** client authentication (FAPI-1.0-Advanced requirement) — not a client secret.
- The consent-status endpoint uses a **client_credentials** token, not the just-obtained PSU bearer token. This allows HSBC to report the consent status independently of the PSU session.
- Both PSU access token and refresh token must be stored in **EncryptedSharedPreferences** (Android) — never in plain SharedPreferences or memory only.
- On a security_error (state/nonce mismatch), neither endpoint is called. `navigateLogin()` revokes any existing tokens via TokenStore before navigating.
