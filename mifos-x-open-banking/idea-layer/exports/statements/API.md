## GET /accounts/{AccountId}/statements

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| AccountId | string | yes | OBIE AccountId from GET /accounts |

### Response: OBReadStatement2 (HTTP 200)

**Data path**: `OBReadStatement2.Data.Statement[]`

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| StatementId | string | yes | Unique statement identifier |
| StatementReference | string | yes | Human-readable reference |
| StartDateTime | string (ISO-8601 UTC) | yes | Statement period start; used to derive periodLabel via kotlinx-datetime |
| EndDateTime | string (ISO-8601 UTC) | yes | Statement period end; used to derive endDateFormatted |
| StatementAmount[] | OBStatementAmount1 | yes | Includes Type: OpeningBalance and ClosingBalance; each has Amount (decimal string) + Currency (ISO 4217) |

**Permission note**: `ReadStatementsDetail` required (not just `ReadStatements`) so that `StatementAmount` (balances) is included in each OBStatement2 record.

**Sort**: ViewModel sorts descending by StartDateTime before rendering.

## GET /accounts/{AccountId}/statements/{StatementId}/file

### Path Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| AccountId | string | yes | OBIE AccountId |
| StatementId | string | yes | Statement identifier from OBReadStatement2.Data.Statement[].StatementId |

### Request Headers

| Header | Value | Required |
|--------|-------|----------|
| Accept | `application/pdf, text/csv` | yes |

### Response

Binary file stream (PDF or CSV). Response DTO is null — bytes are passed directly to the platform file handler.

- **On success**: bytes dispatched to platform file handler (ShareSheet on Android / Files/Downloads on iOS); `downloadState[statementId]` → Idle
- **On error**: `downloadState[statementId]` → Idle; error surfaced as toast (no screen state change)

### Error Mapping

| HTTP | UI Behaviour | Retry |
|------|--------------|-------|
| 501 | Toast: `strings.statements.download.toast_unavailable` — "Statement download not available for this account type." No screen state change; no auto-retry. | no |
| 401 | Toast / inline error — token refresh required before retry | manual |
| Network error | Toast: `strings.statements.download.toast_error` | manual |

**HSBC sandbox note**: HTTP 501 is expected for certain account types in the sandbox environment. Surface the `toast_unavailable` string and do not retry automatically.

| Consumer | Usage |
|----------|-------|
| statements | Per-row download icon (`download_statement_button`) — per StatementId in the list |
| statement-detail | View / download action from the statement detail screen |
