## Error Handling

All endpoints follow standard error mapping:
- 401 → Auth error (redirect to signin)
- 403 → Consent scope missing (ReadStatementsDetail)
- 429 → Rate limit exceeded — surface Retry with back-off hint
- 501 → Download not supported for this account type — surface toast, no retry
- 500 → Server error (retryable)
