- **Errors**:
  - `HTTP_401` — Session expired. Please re-authenticate. (retry=true)
  - `HTTP_403` — Consent does not include ReadStatements. (retry=true)
  - `HTTP_429` — Too many requests. Please wait and retry. (retry=true)

  - `NETWORK_ERROR` — Device offline or AIS endpoint unreachable. (retry=true)
- **Events**: download success → platform file handler; HTTP 501 → toast; error → toast
- **Actions**:

  - `navigateToStatementDetail(statementId: String, accountId: String)` — NavController navigate
  - `retryLoad(accountId: String)` — delegates to statementsLoad
  - `downloadStatement(statementId: String, accountId: String)` — GET statement file; dispatches to platform
- **DI**: ktorfit (rest-client), kotlinx-datetime (datetime)
