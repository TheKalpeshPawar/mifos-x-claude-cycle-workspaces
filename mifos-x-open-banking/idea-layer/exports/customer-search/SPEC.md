## Overview

The Find Customer screen is the primary customer discovery tool for Mifos field officers. It provides real-time search across the officer's portfolio by name, customer ID, phone number, or email, complemented by QR code scanning for in-field identification. Filter chips allow narrowing results by status (All, Active, Prospect, Dormant), and result cards surface KYC status, account balance, and last interaction age at a glance. Officers can also initiate new individual or business customer onboarding directly from this screen.

## States

| ID | Trigger | Description |
|---|---|---|
| idle | Screen mount before any search | Title, search input, filter chips, QR scan button, and onboard buttons visible; results hidden |
| searching | User types ≥2 characters | Skeleton shimmer shown for result cards; onboard buttons hidden |
| results | API returns matches | Customer result cards shown; onboard buttons returned |
| no_results | API returns empty list | Empty state box and message shown; QR scan button hidden; onboard buttons visible |
| error | Network failure | Error message shown; result area hidden |
