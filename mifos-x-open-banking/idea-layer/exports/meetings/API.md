## GET /obp/v3.1.0/banks/{bankId}/meetings

Retrieves all meetings for the bank. The ViewModel filters the response client-side by `selectedDate` to populate the calendar strip and meeting list.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |

### Response Fields

| Field | Type | Description |
|---|---|---|
| meeting_id | String | Unique meeting identifier |
| provider | String | Meeting provider (e.g. "Google Meet", "In-Person", "Phone") |
| provider_id | String | Provider-specific meeting identifier (e.g. Google Meet link ID) |
| purpose_id | String | Meeting purpose code (e.g. "account_opening", "kyc_review") |
| bank_id | String | Bank identifier |
| present | Present | Object containing present.{staff_user_id, customer_user_id} |
| keys | Map | Meeting metadata keys |
| values | Map | Meeting metadata values |

### Error Codes

| Code | Meaning |
|---|---|
| 400 | BAD_REQUEST |
| 401 | UNAUTHORIZED |
| 404 | CUSTOMER_NOT_FOUND |

## POST /obp/v3.1.0/banks/{bankId}/meetings

Creates a new meeting. Called when the officer taps "Confirm Meeting" in the schedule bottom sheet.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier |

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| creator.name | String | Yes | Officer's full name |
| creator.email_address | String | Yes | Officer's email |
| creator.mobile_phone | String | Yes | Officer's phone number |
| invitees[].contact_details.name | String | Yes | Customer's full name |
| invitees[].contact_details.email_address | String | Yes | Customer's email |
| invitees[].contact_details.mobile_phone | String | Yes | Customer's phone |
| invitees[].status | String | Yes | Invitation status (e.g. `invited`) |
| purpose_id | String | Yes | Meeting purpose code |
| provider | String | Yes | Meeting type/provider |

### Response Fields

| Field | Type | Description |
|---|---|---|
| meeting_id | String | Created meeting identifier |
| provider | String | Confirmed provider |
| provider_id | String | Provider-specific ID (Google Meet link, etc.) |
| purpose_id | String | Confirmed purpose |
| bank_id | String | Bank identifier |

### Error Codes

| Code | Meaning |
|---|---|
| 400 | VALIDATION_FAILED — missing required nested fields |
| 401 | UNAUTHORIZED |
| 404 | CUSTOMER_NOT_FOUND |

### Note

The OBP meetings endpoint uses a deeply nested body structure with `creator.*` and `invitees[].contact_details.*` — ensure the ViewModel maps `MeetingDraft` to this exact shape before sending.
