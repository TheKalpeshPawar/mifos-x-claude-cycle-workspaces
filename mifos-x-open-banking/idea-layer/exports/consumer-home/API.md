## GET /obp/v5.1.0/my/accounts

**Auth:** DirectLogin
**Tag:** Accounts
**Trigger:** `loadConsumerHome()` on screen open / `RetryLoad` event — fetches primary account summary for balance card

### Response Fields

| Field                  | Type                    | Description                                     |
|------------------------|-------------------------|-------------------------------------------------|
| id                     | String                  | Account identifier                              |
| label                  | String                  | Account display label (e.g. "Primary Checking") |
| balance.currency       | String                  | Currency code (e.g. "GBP")                      |
| balance.amount         | String                  | Account balance amount (e.g. "4250.00")         |
| account_type           | String                  | e.g. "CHECKING", "SAVINGS"                      |
| account_routings       | List\<AccountRouting\>  | Routing numbers / IBANs                         |
| bank_id                | String                  | Bank identifier (e.g. "gh.29.uk")               |

### Sample Display Mapping

- `ch_balance_amount`: `balance.amount` formatted as `£4,250.00`
- `ch_account_name_chip`: `label` value → "Primary Checking"
- Total balance card shows first account from list as primary

### Error Codes

| Code | OBP Error Key              | UI Behaviour                              |
|------|----------------------------|-------------------------------------------|
| 401  | USER_NOT_LOGGED_IN         | Navigate to login screen                  |
| 404  | BANK_NOT_FOUND             | Show `empty` state                        |
| 500  | INTERNAL_SERVER_ERROR      | Show `error` state with retry button      |

## GET /obp/v5.1.0/my/banks/{bankId}/accounts/{accountId}/transactions

**Auth:** DirectLogin
**Tag:** Transactions
**Trigger:** `loadConsumerHome()` on screen open / `RetryLoad` event — fetches last 3 transactions for recent transactions section

### Path + Query Parameters

| Name           | Type   | In    | Value                         | Description                              |
|----------------|--------|-------|-------------------------------|------------------------------------------|
| bankId         | String | path  | gh.29.uk                      | Bank identifier                          |
| accountId      | String | path  | (from accounts response)      | Primary account identifier               |
| limit          | Int    | query | 3                             | Return only the 3 most recent            |
| sort_direction | String | query | DESC                          | Newest first                             |

### Response Fields

| Field                  | Type   | Description                                       |
|------------------------|--------|---------------------------------------------------|
| id                     | String | Transaction identifier                            |
| details.type           | String | Transaction type ("DEBIT" / "CREDIT")             |
| details.description    | String | Merchant or reference description                 |
| details.posted         | String | ISO-8601 posted timestamp                         |
| details.value.currency | String | Currency code (e.g. "GBP")                        |
| details.value.amount   | String | Signed amount e.g. "-3.50", "3200.00"             |
| other_account.holder.name | String | Counterparty name (e.g. "Coffee Shop", "Salary") |

### Sample Display Mapping

- `ch_transaction_item_1`: description "Coffee Shop" + amount "-£3.50" (debit)
- `ch_transaction_item_2`: description "Salary" + amount "+£3,200.00" (credit)
- `ch_transaction_item_3`: description "Supermarket" + amount "-£42.80" (debit)

### Error Codes

| Code | OBP Error Key         | UI Behaviour                                            |
|------|-----------------------|---------------------------------------------------------|
| 401  | USER_NOT_LOGGED_IN    | Navigate to login                                       |
| 404  | ACCOUNT_NOT_FOUND     | Show `empty` state (no accounts configured)             |
| 500  | INTERNAL_SERVER_ERROR | Show `error` state with "Retry" button                  |
