## Client-Side Data Access

Although there are no REST endpoints, the ViewModel interacts with one local data source:

| Data Source | Type | Access | Purpose |
|-------------|------|--------|---------|
| OnboardingDataStore | androidx.datastore (KMP) | Read + Write | Reads `onboarding_completed` Boolean flag on init; writes `true` when PSU completes the flow and navigates to login |

The DataStore read can fail with an `IOException` (surfaced as the `error` state). This is the only failure mode on this screen — it has no HTTP error surface.

## OBIE Consent Scopes Disclosed in UI

The `permissions_overview` step lists all six `OBReadConsent1` scopes that the user is being asked to grant. These are displayed as plain-English list items — they are not fetched from an API:

| OBIE Scope | Plain-English Label | Component ID |
|------------|--------------------|----|
| ReadAccountsDetail | Account details (sort codes, IBANs) | perm_accounts |
| ReadBalances | Account balances | perm_balances |
| ReadTransactionsDetail | Up to 90 days of transactions | perm_transactions |
| ReadStandingOrdersDetail | Standing orders | perm_standing_orders |
| ReadDirectDebits | Direct debits | perm_direct_debits |
| ReadStatementsDetail | Monthly statements | perm_statements |

The consent duration disclosed to the user is **up to 90 days**, revocable at any time via Settings → Consents. This is per OBIE specification for AISPs and is a static disclosure — not fetched at runtime.
