## Overview

This screen is **client-only**: it makes no network calls.

```yaml
# api.yaml
endpoints: []
```

Data is read from and written to two local stores:

| Store | Type | Contents | Role |
|---|---|---|---|
| `BudgetsDataStore` | `DataStore<Preferences>` | Serialised `BudgetEntry` records (category key → limit amount) | Persistence for user-set monthly budget limits |
| `TransactionCache` | In-memory | AIS debit amounts per category for the current calendar month | Read-only source for computing `used` fractions |

No OBIE AIS endpoint is called. No FAPI 1.0 bearer token required. No OBIE permission scope needed.

## Local Data — BudgetEntry

```kotlin
@Serializable
data class BudgetEntry(
    val category: String,   // e.g. "Groceries", "Transport", "Dining"
    val limit: Double       // Monthly spend limit in GBP e.g. 150.00
)
```

Stored in `DataStore<Preferences>` via `kotlinx-serialization`. Keyed by `category` — duplicate category upserts overwrite the existing entry.

### BudgetEntry Lifecycle

| Operation | Trigger | Side Effect |
|---|---|---|
| Read | Screen mount (`budgets_load`) | Deserialise all BudgetEntry records from DataStore; transition Loading → Content/Empty |
| Upsert | `save_budget` action | Validate form, serialise, write to DataStore; re-compute fractions; reset form |
| Delete | `delete_budget` action | Remove entry by category key from DataStore; re-render list; transition to Empty if list empty |
| Error (read) | DataStore IOException on mount | Transition to `BudgetsUiState.Error`; retry button re-triggers mount load |
| Error (write) | DataStore IOException on save or delete | Show snackbar; in-memory list state unchanged; entry remains |

## Transaction Cache — Read-Only

The `TransactionCache` is populated by the AIS transactions screen (not by budgets). The budgets ViewModel reads it to compute `used` values:

```kotlin
val used: Double = transactionCache
    .getDebitsForCurrentMonth()          // all AIS debit amounts in current calendar month
    .filter { it.category == entry.category }
    .sumOf { it.amount }
```

Month boundaries computed via `kotlinx-datetime`:

```kotlin
val currentMonth = Clock.System.now()
    .toLocalDateTime(TimeZone.currentSystemDefault())
    .let { YearMonth(it.year, it.month) }
```

`TransactionCache` holds no sensitive data beyond what the HSBC AIS already returned to this device. The cache is in-memory and scoped to the ViewModel lifecycle.

## Computed Fields (no network)

| Field | Source | Formula |
|---|---|---|
| `used` | TransactionCache | Sum of debit amounts matching `entry.category` in current calendar month |
| `fraction` | `used / entry.limit` | Clamped to `[0.0, 1.0]` |
| `progress_color` | `fraction` | `error` when `fraction >= 1.0`; `primary` otherwise |
| `is_over_budget` | `fraction` | `true` when `fraction >= 1.0` |
| `remaining_label` | `used`, `entry.limit` | `"£{used - limit} over"` or `"£{limit - used} left"` |
| `currentMonthLabel` | `kotlinx-datetime` | e.g. `"June 2026"` |
