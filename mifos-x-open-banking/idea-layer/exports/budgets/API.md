## Error Handling

No network errors possible. Local persistence errors handled as:
- DataStore read IOException on mount → error state (Retry CTA re-runs budgets_load)
- DataStore write fail on saveBudget / deleteBudget → Snackbar with retry; in-memory state unchanged
