## POST /obp/v5.1.0/banks/{bankId}/agents

**Auth:** DirectLogin
**Tag:** Agent
**Trigger:** `submit_registration` action on Register button tap (after client-side validation passes)

### Path Parameters

| Name   | Type   | Value    |
|--------|--------|----------|
| bankId | String | gh.29.uk |

### Request Body Fields

| Field               | Type          | Required | Example              | Notes                                          |
|---------------------|---------------|----------|----------------------|------------------------------------------------|
| legal_name          | String        | Yes      | "Priya Chakraborty"  | Full legal name as on government-issued ID     |
| mobile_phone_number | String        | Yes      | "+254712345678"      | Prefix +254 prepended to 9-digit phone input   |
| agent_number        | String        | Yes      | "AGT-2026-00142"     | Unique agent identifier assigned by Mifos admin|
| currency            | String (enum) | Yes      | "KES"                | One of: EUR, GBP, KES, USD                    |
| supported_services  | List\<String\>| Yes      | ["cash_deposit", …]  | One or more from the supported values below   |
| commission_rate     | Number        | Yes      | 1.5                  | Float, range 0.5–5.0 (inclusive)              |

**`supported_services` allowed values:** `cash_deposit`, `cash_withdrawal`, `account_opening`, `bill_payment`, `fund_transfer`

### Response Fields

| Field                | Type    | Description                                                     |
|----------------------|---------|-----------------------------------------------------------------|
| agent_id             | String  | Unique agent identifier assigned by OBP                         |
| is_pending_agent     | Boolean | `true` if registration submitted and awaiting bank approval     |
| is_confirmed_agent   | Boolean | `true` if agent is already bank-confirmed and active            |
| legal_name           | String  | Echo of submitted legal name                                    |
| mobile_phone_number  | String  | Echo of submitted mobile phone number                           |

### State Transition on Response

| Response                                   | UI State                |
|--------------------------------------------|-------------------------|
| `is_confirmed_agent=true`                  | `confirmed` state       |
| `is_pending_agent=true`                    | `pending_approval` state|
| HTTP 409 `AGENT_ALREADY_EXISTS`            | `agent_number_error` shown |
| HTTP 4xx/5xx (other)                       | `error` state with global banner |

### Error Codes

| Code | Message                    | UI Mapping                                         |
|------|----------------------------|----------------------------------------------------|
| 400  | `INVALID_BANK_ID`          | Global error banner                                |
| 400  | `INVALID_PHONE_NUMBER`     | `phone_error` inline field error                   |
| 401  | `USER_NOT_LOGGED_IN`       | Global error banner; redirect to login             |
| 403  | `INSUFFICIENT_AUTHORISATION` | Global error banner                              |
| 409  | `AGENT_ALREADY_EXISTS`     | `agent_number_error` — "An agent with this number already exists" |
| 500  | OBP server error           | Global error banner                                |
