## POST /obp/v5.1.0/banks/{bankId}/agents

Registers the authenticated user as a field agent for the specified bank. Called when the officer taps "Register as Agent". On success, the response determines which state the screen transitions to: `is_pending_agent: true` → pending_approval state; `is_confirmed_agent: true` → confirmed state.

### Path Parameters

| Parameter | Type | Description |
|---|---|---|
| bankId | String | OBP bank identifier (e.g. `mifos-nairobi`) |

### Request Body

| Field | Type | Required | Example |
|---|---|---|---|
| legal_name | String | Yes | "Priya Sharma" |
| mobile_phone_number | String | Yes | "+254712345678" |
| agent_number | String | Yes | "AGT-2026-00142" |
| currency | String | Yes | "KES" (one of: EUR, GBP, KES, USD) |

### Response Fields

| Field | Type | Description |
|---|---|---|
| agent_id | String | Unique agent identifier assigned by OBP |
| is_pending_agent | Boolean | True when registration requires manual approval |
| is_confirmed_agent | Boolean | True when registration is instantly approved |
| legal_name | String | Confirmed legal name from the registration |
| mobile_phone_number | String | Confirmed mobile number |

### Error Codes

| Code | Message | Handling |
|---|---|---|
| 400 | INVALID_BANK_ID | Show snackbar: "Invalid bank. Contact support." |
| 400 | INVALID_PHONE_NUMBER | Highlight phone field; "Enter a valid 9-digit phone number" |
| 401 | USER_NOT_LOGGED_IN | Redirect to login |
| 403 | INSUFFICIENT_AUTHORISATION | Show snackbar: "You do not have permission to register as an agent." |
| 409 | AGENT_ALREADY_EXISTS | Show snackbar: "An agent with this number already exists." |
