**Description:** Lists authorised accounts via GET /accounts (hsbc-obie-ais-v4.0:accounts) and fans out parallel balance fetches per AccountId via GET /accounts/{AccountId}/balances (hsbc-obie-ais-v4.0:balances) using ktorfit suspend functions with kotlin.coroutines:async/awaitAll. Merges OBReadAccount6 + OBReadBalance1 into AccountWithBalance rows (Nickname, AccountSubType, Currency, InterimAvailable OBCashBalance3 Amount). Checks cached consent ExpirationDateTime: if < 30 days remaining, transitions to consent_expiring state surfacing reconfirmation banner. CreditCard accounts with CreditDebitIndicator=Debit render balance in error colour with 'Balance owed' badge. GlobalMoney/GlobalWallet cards render ISO currency code. Chip group filters AccountWithBalance list by AccountSubType client-side with no API round-trip. Total net balance across GBP accounts displayed in stat_block at top of content. Card tap navigates to account-detail with AccountId.

## 4. ViewModel Contract

**ViewModel:** `AccountsViewModel`

### State

| Field | Type | Notes |
|---|---|---|
| `accounts` | `List<AccountWithBalance>` | Full unfiltered list from API merge |
| `filteredAccounts` | `List<AccountWithBalance>` | Filtered by `activeFilter`; drives `accounts_list` |
| `activeFilter` | `AccountSubType?` | null = show all; set by `filterAccounts` |
| `totalBalanceFormatted` | `String` | Sum of InterimAvailable GBP balances; formatted string |
| `totalBalanceAccountCount` | `Int` | Number of GBP accounts included in total |
| `activeConsentId` | `String` | ConsentId passed to consent-detail on reconfirm |
| `consentDaysRemaining` | `Int` | ChronoUnit.DAYS.between(now, ExpirationDateTime) |
| `isConsentExpiring` | `Boolean` | true when consentDaysRemaining < 30 |
| `uiState` | `UiState` | Drives screen state |

### Sealed Class — UiState

| Member | Notes |
|---|---|
| `Loading` | Both API calls in flight |
| `Content` | Accounts loaded; consent not expiring |
| `ConsentExpiring` | Accounts loaded; consent ExpirationDateTime < 30 days remaining |
| `Empty` | GET /accounts returned empty Data.Account[] |
| `Error` | cause: Throwable; 401 → navigate to login; network → Retry CTA |

| Error | Trigger | Recovery |
|---|---|---|

## 7. API Dependencies

| Endpoint ID | Method | Path | Auth | OBIE Permission |
