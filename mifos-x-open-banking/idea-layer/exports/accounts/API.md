## GET /obp/v5.1.0/banks/{bankId}/accounts

Retrieves the list of all bank accounts for the authenticated user under a given bank.

**Auth:** DirectLogin (header: `DirectLogin token=<token>`)
**Tag:** Accounts

### Path Parameters

| Name | Type | Required | Value |
|---|---|---|---|
| bankId | String | Yes | gh.29.uk |

### Response Fields

| Field | Type | Description |
|---|---|---|
| id | String | Unique account identifier |
| label | String | Human-readable account name (e.g. "Primary Checking") |
| account_type | String | Account classification (CHECKING, SAVINGS, BUSINESS) |
| balance.currency | String | ISO 4217 currency code (e.g. "GBP") |
| balance.amount | String | Current balance as decimal string (e.g. "4250.00") |
| account_routings[].scheme | String | Routing scheme identifier (e.g. "IBAN", "BIC") |
| account_routings[].address | String | Routing address value (e.g. "DE89 3704 0044 0532 0130 00") |

### Error Codes

| HTTP Code | Message | Resolution |
|---|---|---|
| 401 | Unauthorized — DirectLogin token missing or expired | Re-authenticate via POST /my/logins/direct |
| 404 | Bank not found | Verify bankId is "gh.29.uk" |
| 500 | OBP server error | Retry with exponential backoff |
