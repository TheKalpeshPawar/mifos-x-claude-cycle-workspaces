## Error Handling

All endpoints follow standard error mapping:
- 401 → Auth error (clear token store → navigate to login)
- 403 → Consent revoked / permission absent (navigate to consent-list)
- 404 → AccountId not found (stale ref — remove card + snackbar advisory)
- 429 → Rate limited (exponential back-off + retry CTA)
- 503 → HSBC sandbox unavailable (retry CTA)

**Balance fan-out is parallel** (`coroutineScope { accounts.map { async { ... } }.awaitAll() }`). Partial balance failure (one account 403) does NOT propagate to error state — that account card renders without a balance row.
