## GET /obp/v5.1.0/banks/{bankId}/accounts

**Auth:** DirectLogin
**Tag:** Accounts
**Trigger:** `loadAccounts()` on screen open / `RetryLoad` event. Filter operations are client-side only after initial load.

### Path Parameters

| Name   | Type   | Value    |
|--------|--------|----------|
| bankId | String | gh.29.uk |

### Response Fields

| Field                        | Type                   | Description                                      |
|------------------------------|------------------------|--------------------------------------------------|
| id                           | String                 | Account identifier                               |
| label                        | String                 | Account display name e.g. "Primary Checking"      |
| account_type                 | String                 | e.g. "CHECKING", "SAVINGS", "BUSINESS"           |
| balance.currency             | String                 | e.g. "GBP"                                       |
| balance.amount               | String                 | e.g. "4250.00", "6180.50"                        |
| account_routings[].scheme    | String                 | e.g. "IBAN"                                      |
| account_routings[].address   | String                 | e.g. "DE89 3704 0044 0532 0130 00"               |

### Computed Values (client-side)

| Computation     | Logic                                              | Result      |
|-----------------|----------------------------------------------------|-------------|
| totalBalance    | Sum of all `balance.amount` values                 | £12,480.50  |
| totalAccountCount| Count of all accounts returned                    | 3           |
| filteredAccounts| Filter `account_type` by `activeFilter` enum value | Varies      |

### Error Codes

| Code | Message                                              |
|------|------------------------------------------------------|
