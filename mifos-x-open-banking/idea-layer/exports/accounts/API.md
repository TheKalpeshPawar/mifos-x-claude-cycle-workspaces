## Overview

Accounts makes **2 network calls** on screen mount. The first fetches the account list; the second fans out in parallel per AccountId for balances.

| Call | Method | Path | Permission | Parallel? |
|---|---|---|---|---|
| Account list | GET | `/accounts` | ReadAccountsDetail | No (sequential — provides AccountIds) |
| Per-account balances | GET | `/accounts/{AccountId}/balances` | ReadBalances | Yes — `coroutineScope { accounts.map { async { … } }.awaitAll() }` |

Both require a valid FAPI 1.0 bearer token and `network_policy: cellular_allowed`.

### Response Fields Used by UI

| Field path | UI component | Notes |
|---|---|---|
| `Data.Account[*].AccountId` | `account_card` on_click param | Passed as `accountId` to account-detail and to each balances call |
| `Data.Account[*].AccountSubType` | `account_subtype` (labelSmall, secondary) | Also drives `account_type_icon` mapping and `account_type_filter` chips |
| `Data.Account[*].Nickname` | `account_nickname` (titleMedium) | — |
| `Data.Account[*].Account[0].Identification` | `account_number` (bodySmall) | Sort-code + account number display |
| `Data.Account[*].Currency` | `balance_amount` | Used to detect non-GBP GlobalWallet cards; non-GBP renders native currency code |

**State routing:**
- Empty `Data.Account[]` → `UiState.Empty`
- Non-empty → proceed to parallel balances fan-out → `UiState.Content` or `UiState.ConsentExpiring`

### Error Handling

| HTTP Status | Cause | Recovery |
|---|---|---|
| 401 | Access token expired or invalid | Clear token store → navigate to login |
| 403 | Consent rejected, revoked, or ReadAccountsDetail permission absent | Navigate to consent-list for re-authorisation |
| 429 | HSBC rate-limit exceeded (OBIE mandates 500 calls/5 min PSU limit) | Exponential back-off + surface retry CTA |
| 503 | HSBC sandbox unavailable | Surface retry CTA after brief delay |

## Endpoint 2 — Per-Account Balances (parallel fan-out)

```
GET /accounts/{AccountId}/balances

Auth:      Bearer {access_token}   (FAPI 1.0 Advanced — mTLS + signed request)
Accept:    application/json
```

Called for each `AccountId` returned by Endpoint 1 via `coroutineScope async/awaitAll`.

### Path Parameters

| Param | Type | Required | Description |
|---|---|---|---|
| `AccountId` | string | Yes | OBAccount6.AccountId — returned from Endpoint 1 |

### Response — OBReadBalance1

Response path: `Data.Balance[]`

```json
{
  "Data": {
    "Balance": [
      {
        "AccountId": "40051512345678",
        "Amount": { "Amount": "2847.63", "Currency": "GBP" },
        "CreditDebitIndicator": "Credit",
        "Type": "InterimAvailable",
        "DateTime": "2026-07-14T10:00:00Z"
      }
    ]
  }
}
```

### Balance Type Preference

| Priority | Type | Notes |
|---|---|---|
| 1st | `InterimAvailable` | Preferred for display |
| 2nd | `InterimBooked` | Fallback |
| 3rd | `OpeningBooked` | Last resort |

Multi-currency accounts (GlobalWallet) return native currency balance — displayed as-is without GBP conversion.

### CreditDebitIndicator Rendering

| CreditDebitIndicator | AccountSubType | balanceColor | Badge shown |
|---|---|---|---|
| `Debit` | `CreditCard` | `error` | "Balance owed" (tonal badge) |
| `Credit` | any | `on_surface` | none |
| any | non-CreditCard | `on_surface` | none |

### Error Handling

| HTTP Status | Cause | Recovery |
|---|---|---|
| 401 | Access token expired | Mark all accounts as balance_unavailable; surface session-expired error |
| 403 | ReadBalances permission not granted in consent | Show account card without balance row; surface advisory chip |
| 404 | AccountId not found — stale reference (consent revoked mid-session) | Remove stale account card from list; show snackbar advisory |

## Parallelism Contract

```kotlin
// Step 1: sequential
val accounts = apiService.getAccounts().Data.Account

// Step 2: parallel fan-out
val balances: List<OBReadBalance1> = coroutineScope {
    accounts.map { account ->
        async { apiService.getBalances(account.AccountId) }
    }.awaitAll()
}

// Step 3: merge
val accountsWithBalance = accounts.zip(balances) { account, balance ->
    AccountWithBalance(account, balance.Data.Balance.firstPreferred())
}
```

Total latency = `max(all parallel getBalances calls)` after the sequential `getAccounts` completes.

## Consent Expiry Check

```kotlin
val daysRemaining = ChronoUnit.DAYS.between(Instant.now(), consent.ExpirationDateTime)
isConsentExpiring = daysRemaining < 30
uiState = if (isConsentExpiring) UiState.ConsentExpiring else UiState.Content
```

ConsentId is read from `localConsentCache`; not fetched from the AIS surface.
