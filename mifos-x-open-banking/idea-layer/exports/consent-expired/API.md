## GET /aisp/account-access-consents/{ConsentId}

**Auth:** Bearer (PSU access token)
**Tag:** Consent
**Trigger:** `on_mount` — when a `consentId` route argument is present

Reads the current OBIE account-access-consent to confirm it has lapsed before rendering the screen's copy. The ViewModel expects a non-AUTH status here — EXPD (expired by date) or RJCT/CANC (revoked by PSU or bank). If the response unexpectedly returns AUTH the caller routes back to home instead of rendering this screen. If the check fails for any reason (network, 400, 401, 404) the screen falls back gracefully to the `error` state and shows generic renewal copy so the PSU can still reconnect.

The `Status` and `ExpirationDateTime` fields feed the `expired_status_note` reference line rendered in the `content` state: `"consent expired (EXPD) · 12 Mar 2026"`. When `consentId` is null (e.g. cold-start with no stored consent) this call is skipped and the screen renders in the `content` state with generic copy immediately.

| Name       | Type   | Source            | Description                                                     |
|------------|--------|-------------------|-----------------------------------------------------------------|
| ConsentId  | String | stored_consent_id | The stored ConsentId of the lapsed consent passed as a nav arg  |

### Request Headers

### Response Fields

| Field                | Type   | Description                                                                  |
|----------------------|--------|------------------------------------------------------------------------------|
| ConsentId            | String | Echo of the path ConsentId                                                   |
| Status               | String | OBIE consent Status enum — `AWAU` \| `AUTH` \| `RJCT` \| `CANC` \| `EXPD`  |
| StatusUpdateDateTime | String | ISO-8601 UTC timestamp of the last status transition                         |
| ExpirationDateTime   | String | ISO-8601 UTC timestamp when the consent expired (bound to the reference line)|

> The `expired_status_note` component binds `Status + ExpirationDateTime` into the display string: **"consent expired (EXPD) · 12 Mar 2026"**. For the RJCT/CANC case the label reads "consent revoked (RJCT) · 10 Jun 2026".

### Error Codes

| Code | Name                       | UI Behaviour                                                                       |
|------|----------------------------|------------------------------------------------------------------------------------|
| 400  | CONSENT_STATUS_CHECK_FAILED | Transition to `error` state; hide reference line; show generic renewal copy; Reconnect CTA still active |
| 401  | UNAUTHORIZED               | Transition to `error` state; "Your session has ended. Please reconnect to continue." |
| 404  | CONSENT_NOT_FOUND          | Transition to `error` state; "Your previous connection is no longer available. Please reconnect." |

---

> **Note:** The "Reconnect" CTA does not call any endpoint on this screen. It navigates to `consent-request`, which re-issues `POST /obie/open-banking/v4.0/aisp/account-access-consents` (Status AWAU) to start a fresh consent. This screen is read-only.
