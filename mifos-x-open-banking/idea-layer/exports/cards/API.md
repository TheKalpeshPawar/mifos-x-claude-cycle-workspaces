## Error Handling

All endpoints follow standard error mapping:

- 401 → Auth error (OBP-20001: User not logged in) → redirect to signin
- 404 → NotFound error
- 422 → Validation error
- 500 → Server error (retryable)

```
    → success: populate carousel, resolve card.account.id
      → GET /obp/v4.0.0/banks/{bankId}/accounts/{accountId}/owner/transactions
        → success: populate transaction list (uiState = Content)
        → 401: navigate_login
    → 401: navigate_login
    → no cards: uiState = Empty
    → error: uiState = Error (show retry)
```
