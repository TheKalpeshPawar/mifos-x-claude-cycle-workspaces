## GET /obp/v5.1.0/banks/{bankId}/cards/{cardId}

**Auth:** DirectLogin
**Tag:** Cards
**Trigger:** Screen entry — loads card data for the card passed via navigation argument

### Path Parameters

| Name   | Type   | Description                                          |
|--------|--------|------------------------------------------------------|
| bankId | String | OBP bank identifier (e.g. "gb.mifos")               |
| cardId | String | Card unique identifier (from the cards list screen)  |

### Response Fields

| Field            | Type           | Description                                              |
|------------------|----------------|----------------------------------------------------------|
| id               | String         | Card identifier                                          |
| bank_id          | String         | Issuing bank identifier                                  |
| bank_card_number | String         | Masked PAN (e.g. "************4521")                    |
| name_on_card     | String         | Cardholder name (e.g. "Alex Johnson")                   |
| card_type        | String         | "debit" or "credit"                                      |
| card_description | String         | Display name (e.g. "Mifos Debit Visa")                  |
| card_network     | String         | "VISA" or "MASTERCARD"                                   |
| allows           | List\<String\> | Permitted operations (e.g. "credit", "debit", "cash")   |
| enabled          | Boolean        | false when card is frozen or deactivated                 |
| cancelled        | Boolean        | true when card has been permanently cancelled            |
| on_hot_list      | Boolean        | true when card has been reported lost or stolen          |
| technology       | String         | Card technology (e.g. "CHIP_AND_PIN")                   |
| expires          | String         | Expiry date in YYYY-MM format (e.g. "2029-09")          |
| replacement      | CardReplacement| Replacement card details if applicable (nullable)        |

### Error Codes

| Code | Message                    | UI Behaviour                                   |
|------|----------------------------|------------------------------------------------|
| 400  | INVALID_CARD_ID            | Show error state with retry                    |
| 401  | USER_NOT_LOGGED_IN         | Redirect to login                              |
| 403  | INSUFFICIENT_AUTHORISATION | Show error state with support message          |
| 404  | CARD_NOT_FOUND             | Show empty state "Card information not available" |
