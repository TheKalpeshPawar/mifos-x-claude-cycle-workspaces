### Auth / Consent Notes

- `ReadBeneficiariesDetail` must be present in the PSU's active account-access-consent. If the permission was not included when the consent was originally granted, the endpoint returns HTTP 403.
- The optional `x-fapi-interaction-id` request header, if provided, is echoed back in the response — useful for correlating logs between client and HSBC AIS.

### Error Handling

| HTTP Status | OBIE Error Code | Description | UI Action |
|---|---|---|---|
| 401 | `UK.OBIE.Header.Invalid` | Access token expired or invalid | Show error state with Retry CTA; ViewModel clears stale token |
| 403 | `UK.OBIE.Resource.ConsentMismatch` | ReadBeneficiariesDetail permission absent from active consent, or consent has been revoked/expired | Show error state with View Consents CTA; navigate to consent-list |
| 429 | `UK.OBIE.Rules.TooManyRequests` | Rate-limited by HSBC; retry after Retry-After header interval | Show error state with Retry CTA; ViewModel applies exponential back-off |
| 500 | `UK.OBIE.Unexpected.ServerError` | Unexpected HSBC server error | Show error state with Retry CTA |
| network / timeout | IOException | Device offline or HSBC AIS unreachable | Show error state with Retry CTA |
