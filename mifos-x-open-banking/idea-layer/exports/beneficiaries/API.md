# API Reference — Beneficiaries
**Feature:** beneficiaries | **Base URL:** https://apisandbox.openbankproject.com

---

## GET /obp/v4.0.0/banks/{bankId}/accounts/{accountId}/{viewId}/counterparties

Retrieves the full list of counterparties (beneficiaries) registered on a given account view. Counterparties represent saved payees that the account holder can send money to.

**Auth:** DirectLogin (assumed — `DirectLogin token=<token>`)
**Tag:** Counterparties

### Path Parameters

| Name | Type | Required | Example |
|---|---|---|---|
| bankId | String | Yes | gh.29.uk |
| accountId | String | Yes | acc_checking_primary |
| viewId | String | Yes | owner |

### Response Fields

| Field | Type | Description |
|---|---|---|
| counterparties | List\<Counterparty\> | Array of counterparty objects |
| counterparties[].id | String | Unique counterparty identifier |
| counterparties[].name | String | Beneficiary display name (e.g. "John Smith") |
| counterparties[].description | String | Optional description / relationship note |
| counterparties[].other_bank_routing_address | String | Beneficiary bank routing address (e.g. sort code, BIC) |
| counterparties[].other_account_routing_address | String | Beneficiary IBAN or account number |
| counterparties[].other_account_routing_scheme | String | Routing scheme: "IBAN", "AccountNumber", etc. |
| counterparties[].is_beneficiary | Boolean | Whether this counterparty is flagged as a trusted beneficiary |
| counterparties[].created_by_user_id | String | OBP user ID who created this counterparty |

### Error Codes

| HTTP Code | Message | Resolution |
|---|---|---|
| 400 | INVALID_BANK_ID | Verify bankId is "gh.29.uk" |
| 401 | USER_NOT_LOGGED_IN | Re-authenticate via POST /my/logins/direct |
