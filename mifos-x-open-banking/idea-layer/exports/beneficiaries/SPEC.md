**Description:** Calls GET /accounts/{AccountId}/beneficiaries via ktorfit to retrieve OBReadBeneficiary5. Maps each Data.Beneficiary using CreditorAccount.SchemeName (mapped to a human-readable label: UK.OBIE.SortCodeAccountNumber→Sort Code, UK.OBIE.IBAN→IBAN, UK.OBIE.Paym→Paym), Identification, Name, and Reference into list rows. An avatar with initials is derived from CreditorAccount.Name for visual identity. Supports client-side search filtering by Name or Reference (no extra API call). Surfaces typed errors: TokenExpired 401 (retry CTA re-fetches), ConsentRevoked 403 (View Consents CTA navigates to consent-list), RateLimited 429 (retry with back-off), NetworkError (retry). On empty list shows no-payees state.
