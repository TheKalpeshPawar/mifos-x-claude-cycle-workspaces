## Design Notes

**Visual Differentiation Between Active and Expired Consents:**
- Active card: white background, elevation 2, #EDE7F6 purple scope chips, #4CAF50 ACCEPTED badge — visually prominent and trustworthy
- Expired card: #FAFAFA background, elevation 1, #F0F0F0 grey scope chips, #9E9E9E EXPIRED badge — visually receded, communicating "this no longer matters"
- This differential treatment helps users instantly understand which consents are live risks

**The Revoke Button:**
- "Revoke Access" uses #FF5252 red — a deliberate danger-signal colour, not the brand primary; it should feel slightly alarming to avoid accidental revocations
- "Remove" for expired consents uses neutral #9E9E9E text variant — no danger signal because the access is already gone

**Color System:**
- Primary #1800B1 is reserved for the page title only — it does not appear on consent cards, preserving its brand authority
- Scope chips use #4527A0 purple on #EDE7F6 — a lighter purple family that relates to the brand without being the brand primary
- Status badges are purely semantic: green = active, grey = expired

**Accessibility:**
- Each consent card has a single comprehensive a11y label: "MoneyDash Finance. Granted 12 March 2026. Access: accounts, balances, transactions. Status: Active."
- Revoke and Remove buttons describe the full context: "Revoke MoneyDash Finance access to your account data"
- Status badges use role="status" so screen readers announce consent state changes
