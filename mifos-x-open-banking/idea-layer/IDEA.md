## Problem

Bank account data is locked inside each bank's own app, and the only way to share it used to be
insecure password sharing. UK Open Banking provides a regulated, consent-based, API-first
alternative — but few apps demonstrate the standard's full AISP surface end to end.

---

## Solution

A Kotlin Multiplatform (Compose) client that performs the OBIE FAPI 1.0 Advanced consent journey
against HSBC and surfaces the complete Account & Transaction API as clear, accessible screens.

**In scope**

- AISP read-only account information across all HSBC sandbox AIS resources.
- Full FAPI consent journey + consent lifecycle management (dashboard, revoke, 90-day reconfirm).
- Global Money / Global Wallet accounts rendered in the accounts list and account detail — no
  dedicated multi-currency surface and no Global filter chip.
- **PISP consumer-initiated domestic single payments** — the PSU pays a person from their own
  authorised account. `Risk.PaymentContextCode` is restricted to the consumer values
  `TransferToThirdParty` and `TransferToSelf`; merchant-checkout contexts and merchant `Risk`
  fields are forbidden.
- Detached JWS (`x-jws-signature`, PS256, `b64:false`) and `x-idempotency-key` on every PISP write.

**Out of scope**

PISP scheduled payments and standing orders · all international payment variants · merchant /
e-commerce checkout contexts · VRP, file and multi-bill payments · CBPII as a standalone
capability · beneficiary edits · field-officer surfaces · production TPP enrolment · ATM/branch
locator · PFM dashboard, spending-by-category, budgets, recurring subscriptions.

**Regulatory note.** PISP is a distinct FCA permission from AISP. Sandbox operation is unaffected;
production payment initiation would require authorisation this project does not hold. Tracked as an
ADR — **which is not yet written**.

## Constraints & Assumptions

**Technical** — mTLS with HSBC-issued sandbox certs (platform-specific, expect/actual) · FAPI 1.0
Advanced: signed request object, PKCE S256, `private_key_jwt`, app-to-app redirect.

**Business** — credentials never hardcoded (RULE-CREDS-LIFECYCLE-001) · GDPR / consent transparency
per OBIE Customer Experience Guidelines.

**Assumptions** — developer holds HSBC sandbox certs, `client_id` and SSA · target brand HSBC UK
Personal, OBIE v4.0.

**Known limitation** — sandbox account subtypes are limited to CurrentAccount, Savings, CreditCard,
Global Money and Global Wallet; no loans or fixed deposits.
