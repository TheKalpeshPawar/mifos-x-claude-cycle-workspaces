# mifos-x-open-banking

UK Open Banking **AISP** (Account Information) reference app — Kotlin Multiplatform / Compose
Multiplatform, built against the **HSBC UK sandbox** to OBIE Read/Write v4.0.

- **Role:** AISP — read-only account information (no payment initiation).
- **Auth:** FAPI 1.0 Advanced (mTLS + DCR + OAuth2 auth-code/PKCE + signed request object).
