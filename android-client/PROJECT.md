## Tech Stack

- **Kotlin** 2.2.21 + **Compose Multiplatform**
- **Architecture**: MVI (template-derived `BaseViewModel` + `Effect.kt`)
- **DI**: Koin 4.1.1
- **Network**: Ktorfit 2.7.1 against **Mifos Fineract REST API**
- **Database**: Room 2.8.4 + sqlite-bundled 2.6.2
- **Observability**: Firebase BOM 34.7.0
